# 연등광장 높이와 천왕문 연결 보완

## Milestone · M2 공간 보완 / M4 웹 검수
연등광장에서 연등 아래를 걷는 느낌을 살리도록 높이를 낮춘다. 구현 후 사찰 분위기 보완에 대한 의견만 제시하며 추가 분위기 기능은 착수하지 않는다. 목표 날짜 없음.

## Epic · E01 공간 구성(#1), E04 웹 검수(#4)
포함은 천왕문 처마 시작점 유지·광장으로 완만히 낮아지는 연등·횡방향 중앙의 약한 처짐, 장식 연등 연결, 줄/이름표/LED/후광/선택 표시/상세 말풍선의 동일 높이 정렬이다. 제외는 고정 슬롯 ID와 저장된 위치 계약, X/Z 배치·색/한지/수량·구매 로직·건물/현판·보행 변경이다.

## Implementation Issue 후속
- 기존 #18·#23·#25(M2): 저장된 슬롯에 프레젠테이션 높이 프로필을 적용한다. 처마 가장 가까운 첫 줄은 원래 높이, 연등광장은0.85~1m 낮아진다. 중앙을 가장자리보다 최대0.15m 더 낮춘다. 장식 연등은 광장의 마지막 줄 높이에서 시작해 대웅전 앞 기존 끝 높이4.35m로 부드럽게 이어진다. 선행은 사용자 높이 조정 승인. 완료 조건은 줄·등·빛·이름표·클릭/상세 위치 일치와 현판 시야 유지. 검증은 순수 함수·같은 시점 낮밤·실제 클릭/말풍선 검사. 예상 S.
- 기존 #64·#66·#77(M4): 보행·구매/재입장·데이터/광학 재질 보존·공개 체험판 검수. 선행은 위 높이 프로필. 완료 조건은 보행 높이/화면 울렁임 변경 없음, 531개 계약 전체 보존, 한지/LED와 상세 정보 유지다. 예상 S. 예비 시간·배포 대기는 별도. 새 Issue/상태/승인 변경 없음.

## 데이터와 화면 좌표
서버의 고정 슬롯 계약과 소유권·예약은 수정하지 않는다. 렌더러·선택 고리·이름표·상세 말풍선은 같은 표시 프로필 함수를 사용한다. 기존 데이터의 높이를 이중 적용하지 않는다. 광장 본체 하단은3.8m 이상으로 보행자 머리 위 여유를 확보한다.

## 검수 결과
원본84개·독립 체험판20개 단위 검사 및 타입/빌드 통과. 440개 실제 등 몸체 위치가 표시 프로필과 일치한다. 천왕문/광장 눈높이에서 대웅전 현판 방향 광선에 연등이 가리지 않는 것을 검사하고 같은 각도 낮밤 전후를 확인했다. 비회원 신청→시험 로그인→설치→이름표 높이·실제 클릭 상세 말풍선·클릭 보행 통과. 기존 다섯 아이템 구매·재입장·개인 전시·수행·모바일 동선 통합 검사 통과. 531개 서버 슬롯 계약과 승인된 한지 셰이더 원문은 유지한다.

증거는 evidence/lower-canopy/. 재현은 독립 체험판 scripts/check-lower-canopy.mjs, check-lower-canopy-views.mjs, check-trial.mjs. 사찰 분위기에 대한 제안은 의견이며 추가 구현을 하지 않았다.

공개 체험판 v17 반영 완료. 배포 후 440개 높이·현판 시야·신청/이름표/상세 클릭 검사 통과. GitHub 커밋·푸시는 이번 요청 범위에 없어 수행하지 않았다.
