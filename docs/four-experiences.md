# 동전·창밖 풍경·해태·공동 모금 체험

사용자 승인 범위: 네 항목 모두 구현. 가격과 실제 결제는 계속 보류한다. 공동 모금은 공사 시설 한 곳부터 가상 포인트로 시험한다. 기존 건물·판매 자리·아이템·수행·스님·방문자 동기화는 유지한다.

## Milestone / Epic / Implementation 대응

기존 Issue 번호·내용·상태는 변경하지 않고 다음 후속 범위로 정리한다. 새 GitHub Issue나 Milestone을 자동 생성하지 않는다.

- M2 / Epic #1 / Implementation #23 후속: 천왕문 접근 통로 양옆 낮은 화강암 해태 한 쌍. 가운데 통행과 안내 스님 공간 확보. 예상 S.
- M3 기능 확장 / Epic #1 / 로컬 Implementation F01: 3초 소원 카운트, 1/4 확률을 보존하고 비행 시간을 1.5초로 늘림. 비행 동전만 조금 확대하고 황동 재질 보완. 캐릭터·도착 지점을 담는 별도 시점으로 부드럽게 전환, 결과 뒤 기존 보행 시점 복귀. 사용자가 회전·줌·이동하면 시점 연출 중단. 효과 완화에서는 시점 이동 생략. 예상 S.
- M3 기능 확장 / Epic #1 / 로컬 Implementation F02 — 개인 공간 후속: ‘창밖 풍경’에서 연못·도심 야경·한강뷰·밤바다·산뷰 선택. 브라우저의 마지막 선택 유지. 실사진이나 실제 서울 지형의 정밀 복제가 아닌 가벼운 3D 풍경. 선택한 풍경만 생성하고 교체 시 해제. 기존 불단·수행·아이템 전시·귀환 유지. 예상 M.
- M3 기능 확장 / 로컬 Epic 공동조성 시험 / Implementation F04(아직 GitHub 번호 없음): 공동 모금은 기존 거래 Issue의 완료로 표시하지 않는 신규 승인 범위다: 준비→기초→기둥→지붕→완공, 공사/완공 시설 클릭과 가까운 버튼에서 진행·명단 확인. 이름 공개는 직접 동의한 경우만. 공용 시험 서버의 원자적 파일 저장으로 방문자 간 공유 및 재시작 복구, 요청 번호 중복 방지. 시험 목표 100,000포인트, 1,000·5,000·10,000포인트. 실제 돈·후원 영수증·상품/가격/결제 변경 제외. 예상 M. 정식 모금 운영 단계는 미확정이며 임의 출시 계획을 만들지 않는다. F01·F02·F04는 이번 승인 범위를 구분하는 로컬 작업 ID이고 기존 GitHub 번호가 아니다.
- M4 / Epic #4 / Implementation #64·#66 및 Epic #74 / #77 후속: PC·터치 조작, 재입장, 중복 참여, 두 브라우저 공유, 익명/공개 명단, 완공, 기존 접속 동기화, 13개 번역 사전 신규 UI 문구 검사. 예상 S. 시험·배포 대기 시간은 구현량에 중복 가산하지 않는다.

## 완료 조건 및 선행 조건

- 네 기능은 사용자 승인으로 착수. 공동 모금 서버는 기존 Mac Colyseus의 같은 임시 HTTPS 주소를 사용한다. Mac과 임시 연결이 실행 중이어야 공유 기능이 작동한다.
- 개인 공간 풍경은 같은 브라우저의 기기 설정이며 계정 간/기기 간 클라우드 동기화로 표시하지 않는다. 밤 풍경을 골라도 공용 사찰의 낮·밤 설정을 바꾸지 않는다.
- 시험 모금은 성공 응답을 받아야 진행률을 갱신하고, 실패 시 재시도 안내. 진행·명단은 최대 5초 간격 갱신. 내부 방문자 키·요청 키·개인별 금액은 공개 응답에서 제외한다. 기본 이름 비공개. 완공 후 추가 참여 차단, 기존 명단 유지.
- 실제 모금 운영, 금액·목표·환불·관리자 확정, 영수증·실결제는 후속. 본 결과는 실제 과금 기능 완료를 의미하지 않는다.

## 검증

- 본 서비스 단위 검사 114건, 시험 모금 저장소 검사 2건. 기존 슬롯 고정·동작·동선 검사 포함.
- scripts/check-four-features.mjs: PC에서 동전 실비행 화면 안 표시·기존 시점 복귀, 다섯 풍경과 재입장 선택 유지, 천왕문 해태 화면, 두 독립 브라우저의 공유 진행·명단·완공, 모바일 390×844 모금 화면.
- 시험 모금은 별도 18833 서버와 /private/tmp의 시험 파일로 검수한다. 체험판의 실제 시험 누적치를 QA 때문에 채우거나 초기화하지 않는다.
- 증거: evidence/four-features. 실휴대폰·50명 부하·실결제 검수로 간주하지 않는다.

최종 추가 검수: 터치 화면에서 다섯 풍경 선택 직후 창가 시점 자동 전환, 내 모습 복귀, 산뷰 선택 후 재입장 저장 확인. 모금 서버 통합 검사 5건 통과(기존 3인 동기화·채널 정원 포함). 새 모금 시설은 지도 시설 항목에서 찾을 수 있으며 시험 누적치는 0으로 시작한다.
