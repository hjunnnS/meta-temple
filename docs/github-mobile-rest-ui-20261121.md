## 변경 및 검수

모바일 화면·터치 좌표, 지도·메뉴 가독성, Safari 입장 복구, 원거리 건물·방문객 처리와 그래픽 메모리 사용을 조정했다. PC 모델·재질·텍스처 품질 비교를 통과했다. 고정 조건 비교의 draw calls는 낮 560.2→486.5, 밤 570→496.3이며 JS heap 마지막 표본은 303,649,412→292,188,316바이트다. 최장 초기 작업은 206→214ms로 개선이 입증되지 않았다. 실제 iPhone의 온도·배터리·iOS 메모리 한도는 측정하지 않았다.

의자를 터치해 이동·앉기, 드래그 오작동 방지, 요청 시 주문창 열기·닫기·착석 유지, 개인 공간의 접히는 메뉴를 구현했다. 수행 상태·시간·자동 108배 횟수는 유지했다. 단위 검사 원본 135개·체험판 74개와 두 빌드를 통과했다. WebKit·Chrome의 모바일 모의 환경 및 PC에서 검사했고, 공개 v60에서도 의자·주문·개인 메뉴·명상 타이머·108배 횟수·사찰 복귀를 확인했다. 108회 완료 경계는 107회 시작 시험 응답을 사용했으며 전체 108회 실시간 실행을 뜻하지 않는다.

모바일 정상 애니메이션 WebKit 연속 검사 619초 동안 재로딩·그래픽 연결 손실은 없었다. 독립 브라우저 세 세션에서 Colyseus 이동·외형·수행·개인 공간·퇴장을 확인했다. 이는 실제 휴대폰이나 실제 참가자 평가를 대신하지 않는다.
