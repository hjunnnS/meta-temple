## 표현과 운영 경계

대웅전 3자리, 관음전·지장전 각 1자리, 뒤쪽 네 전각 각 1자리, 인등전 앞 1자리, 연등길 2자리, 구름탑 2자리, 연못 2자리, 쉼터 1자리, 뒤 산책길 2자리, 미륵보살 석상 앞 1자리로 총 20개 풀을 유지한다. 실제 본인 1명이 들어오면 대웅전의 추가 1자리부터 비워 가상 19명을 표시한다. 실제 인원이 늘면 멀리 있는 기존 방문객부터 1.25초에 걸쳐 사라지며 줄면 복원한다. 기존 스님 5명과 강아지는 이 풀에 포함하지 않는다.

이들은 LLM 대화 계정이 아닌 배경 행동 NPC다. 가까이에서 '가상 방문객'을 표시하고 14개 언어를 적용한다. 실제 방문자 수에는 더하지 않고 구매·예약·음성·기도 완료 효과를 발생시키지 않는다. 입구와 사용자 수행 자리를 비우며 산책자는 가까운 사용자에게 양보한다.

애니메이션은 근거리에서만 20Hz, 먼 거리에서는 느리게 갱신한다. 38m 이상은 같은 모델·재질의 합쳐진 고정 자세로 전환해 원거리 draw call을 줄인다. 새 실시간 그림자나 네트워크 세션을 추가하지 않는다. 화면 이탈 및 개인 공간에서는 동작을 멈추고 개인 공간에서는 전부 숨긴다. 기존 건축/아이템/PC 품질/판매 좌표는 유지한다.

Sites는 여전히 브라우저별 단독 체험판이다. 실제 다른 브라우저의 인원을 측정하지 않는다. 자동 감소는 원본 서비스의 서버 count에 연결되어 있으며 체험판에서는 같은 응답 형식의 10명/20명 모의 응답으로 검증했다. 서버 미연결을 실제 다인 연동 완료로 표시하지 않는다.

## 서버 인원에 대한 제안

현재 서버 코드는 채널당 실제 20명, 3개 채널을 설정한다. 설정상 60개 동시 세션 슬롯이 있어도 60명 부하 통과를 의미하지 않는다. 기존 근거는 로컬 독립 20세션 검수다. 초반 운영은 채널당 20명, 서버 전체 실제 20명부터 시작하는 안을 권장한다. 서버 전체 50명은 채널을 분리하고 실제 배포 사양에서 20→30→50명 부하/응답 지연/클라이언트 성능을 확인한 뒤 확장 목표로 다룬다. 서버 사양이 미정이므로 최대 수용 인원을 확정하지 않는다. 실제 서버 제한은 이번 작업에서 바꾸지 않는다.
