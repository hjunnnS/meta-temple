# 기존 Issue 기준 잔여 작업

2026-11-21 GitHub Issue 본문·댓글과 현재 구현/검수 자료를 대조했다. 이번 요청은 목록 정리이며 다음 구현 착수 승인이 아니다. 기존 번호·내용·승인 상태와 실제 Milestone을 변경하거나 중복 Issue를 만들지 않는다. 날짜는 새로 정하지 않는다. 닫힌 Issue의 후속 검증은 미구현 기능과 구별한다.

이번 모바일 최적화·UI 후속은 공개 체험판 v61에 반영됐다. 원본 141개·체험판 80개 단위 검사, PC 품질 비교, WebKit/Chrome 모바일 모의 환경의 지도 각 40회·약 310초 연속 검사, 세 독립 브라우저의 Colyseus 공유와 게시 후 동작 확인을 완료했다. 상세 근거는 [이번 구현·검수](mobile-followup-20261121.md)와 연결한다. 이 결과는 실제 iPhone 온도·배터리·장시간 수용 검증이나 20개 브라우저 부하 검증을 대신하지 않는다.

## 우선순위

1. **실제 iPhone 14 Pro Safari 수용 검증** — M4 / Epic #4 / Implementation #66의 후속. #66은 닫혀 있지만 기존 PC 검수와 이번 모바일 모의 검수에는 실제 기기 발열·장시간 메모리 검증이 포함되지 않았다. 입장·지도·메뉴·사찰/개인 공간 왕복의 재로딩, 장시간 사용과 온도·배터리 변화를 확인한다. 초기 long task는 최종 비교 204→220ms로 개선이 입증되지 않았으므로 실제 기기의 첫 입장·재입장 로딩도 확인한다. 구현한 지연 생성·캐시·UI를 다시 개발하는 항목은 아니다. 선행: 실기기 접근. 완료 조건: 실기기 기록과 재현 가능한 문제의 해결 확인. 검증: Safari 진단과 반복 사용 기록. 예상량: 검증 M, 기기 확보 대기는 별도, 수정량은 재현 후 산정한다.
2. **현재 Colyseus의 다중 브라우저 부하·장시간 검증** — M4 / Epic #3 / Implementation #68의 후속. #68은 닫혔고 SDK 20연결·21번째 제한 및 독립 브라우저 3개 검수는 완료했다. 현재 전환본의 20개 실제 브라우저 부하와 장시간 이동·재연결의 수렴·성능은 별도 검증이 남는다. 선행: 안정적인 시험 서버와 부하 실행 환경. 완료 조건: 세션/이동/재연결의 일관성과 자원 사용 기록. 예상량: 검증 M, 환경 준비 대기는 별도. 수용 인원 확대를 미리 확정하지 않는다.
3. **정식 운영 환경 연결 및 인계** — M4 / Epic #4 / Implementation #71(열림), 완료된 #70은 후보 실행의 근거로 참조. 현재 공개 체험판 v61과 Mac 임시 Colyseus 주소는 가동 중이며 체험판 게시 자체를 미완료로 나열하지 않는다. 상시 운영으로 전환할 때 AWS 등 서버·고정 주소, 실제 인증/메일을 사용할 경우의 외부 연결, 운영 담당·개인정보/보존 정책과 배포 승인을 확정한다. 기존 인증·백업·복원·후보 실행을 재개발하는 작업은 아니다. 선행: 사용자의 운영 환경·범위 결정. 완료 조건: 선택한 환경에서 연결·알림·복구 확인과 인계/출시 승인. 검증: 선택한 실제 환경의 운영 점검. 예상량: 환경 결정 전 미산정, 외부 대기 별도. 가격·결제 제공자 연결은 제외한다.

## 개발 목록에서 제외하는 항목

- 이번 모바일 상세 모델 지연 생성·그림자·원거리 방문객·개인 공간 캐시/야경·중복 통신·가로 일정·지도/터치 UI 및 기존 의자 앉기·커피 주문창·개인 공간 메뉴와 수행/가이드/NPC는 잔여 개발로 다시 나열하지 않는다.
- #36 참배 시작·종료·취소는 구현됐다. 남았던 정식 종교 감수는 사용자가 진행하지 않기로 했다. #9 도상 감수와 원어민 번역도 같은 정책을 따른다.
- #64의 실제 5명 식별 평가는 계속 보류한다. #50 아이템 자동 찾기도 기존 보류를 유지한다.
- #5~#12 등 오래된 열린 Issue에는 구현 완료 자료와 후속 승인 항목이 혼재한다. 열린 상태만으로 신규 미구현 기능으로 세지 않는다. 상태 정리는 별도 관리 작업이며 이번에 임의로 닫지 않는다.
- 가격·결제와 미확정 앱 출시·미래 기능은 제외한다.

작업량은 Implementation 후속 기준으로만 산정하며 Epic/Milestone에 중복 가산하지 않는다. 기존 M4 검수의 후속 대응 관계를 사용했고 새로운 Milestone을 만들지 않았다.
