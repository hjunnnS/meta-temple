## 현판 가림·바닥 줄무늬 수정 승인

Milestone: M2 공간 제작 후속 및 M4 웹 시각 회귀. Epic: E01 사찰 공간·E04 웹 검수. Implementation: 기존 #6 배치 및 #64 검수 후속, 새 Issue와 상태 변경 없음. 범위: 관음전·지장전·인등전·종무소·대웅전 실내 현판을 기둥 안쪽에 분리하고 외부 현판 높이를 보정한다. 원거리 카메라의 near 범위를 거리별로 조절하고 중앙 마당 판석과 바닥의 교차를 해소한다. 모델·재질·해상도·주간 그림자 4096·광원 값은 유지한다. 선행: 사용자 수정 승인(충족). 완료 조건: 안쪽 현판 글자 전면 가시성·통행 머리 높이 확보, 기존 글자 방향 보존, 넓은 지도·야간과 보행 검수 통과. 검증: 같은 시점 전후·광원/지형 분리 실험·실제 깊이/가시선 검사·PC/터치·신청/수행 회귀. 예상 작업량 M, 배포 대기 별도.

원인 실험: 그림자 제거만으로는 원거리 줄무늬가 남았다. 동일 시점에서 카메라 near=.1을 1m로 올리면 줄무늬가 사라진다. 흙 면(.006/.012m)과 하부 지형(-.045m)의 가까운 깊이 간격이 원거리에서 충분히 구분되지 않았으며, 중앙 마당 판석(.088±.005m)은 마당 상면(.09m)과 실제로 교차했다. 가까운 보행 near=.1은 유지하고 원거리만 정밀도를 높이며, 마당 위 판석·평탄 보행면은 4cm 올려 면 교차를 제거한다. 돌마다 카메라가 튀는 방식은 사용하지 않는다.

수정 검수 완료: 기존 원본 자동 검사 72개·체험판 8개, 타입·빌드·에셋 19개 출처/해시 검증 통과. 글자 면 24개 정방향·현판 가시선 135/135·머리 높이 확인. 낮 지도 near=1m·그림자 4096 및 야간 화면 검수, PC/터치 확장 체험·다섯 아이템 신청·복원·수행·개인 공간, 대웅전 카메라 120각도와 실제 출입 통과. 런타임 오류·실패 에셋 0. 상세는 체험판 evidence/visibility-ground-fix/result-summary.json.
