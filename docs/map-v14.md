# 승인된 v1.4 맵 재배치 후속

사용자 승인: 추천 지도대로 실제 맵 재배치, 기존 건축·아이템 모델/재질 유지, 구름탑·미륵보살 석상 명칭 적용.

- Milestone: 기존 M2 공간 제작 후속, M4 실제 웹 회귀 검수. 목표 날짜 없음.
- Epic: 기존 E01 사찰 공간·경관 및 E04 웹 검수. 완료된 단계와 Issue의 기존 승인 이력을 보존한다.
- Implementation: 기존 #6 배치 후속, #22 아이템 공간 후속, #64 동선 검수 후속에 대응한다. 새 Issue를 생성하거나 기존 상태를 바꾸지 않는다. 예상 구현량 M, 배포 대기 별도.
- 범위: 관음전·지장전을 북쪽 참배마당 양옆으로 이동, 석탑·봉헌초는 관음전 남쪽, 추모등 네 자리는 지장전 남쪽으로 이전, 종무소를 범종각과 같은 남북 위치로 이동. 동쪽 탑·연못·쉼터 조망을 유지하고 외곽 담은 연결한다. 일주문은 확대된 남쪽 정면 담에 맞춘다.
- 선행: 사용자의 추천 지도 승인(현재 충족). 도상 재제작·불상 추가·상품 수량·가격 변경은 제외한다.
- 완료 조건: 실제 배치와 서비스 지도 일치, 새 명칭 표시, 기존 440 연등 자리 및 모든 아이템 ID/수량/모델/재질 보존, 이동한 자리 좌표와 신청·복원 동기화, 공용 보행·개인 공간·쉼터·연못 접근, 요청한 두 실제 화면 제출.
- 검증: 타입/빌드·자리/경로 검사·Chrome 실제 이동/신청/복원과 스크린샷.

배치 버전 layout-web-015. 연등은 좌표까지 동일하다. 인등·추모등·봉헌초는 고유 ID를 유지하고 새 자리로 이전한다. Sites 체험 저장은 자리 ID로 참조하므로 재방문 시 새 좌표에 같은 아이템을 표시한다. 원본 로컬 PostgreSQL은 초기화 없이 좌표만 원자적으로 갱신한다.

검수 결과: 원본 70개 자동 검사, 체험판 6개 자동 검사 및 타입·빌드 통과. 자리 531개(연등 440·인등 12·추모등 4·소원패 54·봉헌초 21)의 ID/수량 보존. 연등 좌표 전체 해시 동일. Chrome에서 10개 목적지 도착·실제 보행·천왕문→대웅전 입장(끝 Z=28.79), 다섯 신청·복원·수행·개인 공간, PC/터치 확장 동선 통과. 원본 PostgreSQL의 반복 좌표 마이그레이션·소유자/상품 제약·중복 예약 방지 검사 통과. 실결제·다인 동기화 검수는 이번 범위에 포함하지 않는다. 화면은 체험판 evidence/map-v14에 보관한다.
