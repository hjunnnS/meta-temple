# Mac 없이 3명 공동 방문

사용자 승인: 서로의 캐릭터를 보는 3인 테스트, Mac을 꺼도 접속 유지. 기존 M3 / Epic #3 / Implementation #53·#54 및 M4 #68의 후속 연결·검수다. 새 Issue·Milestone은 만들지 않고 기존 완료·승인 상태를 유지한다. 예상 구현 M + 검수 S, 계정/서비스 준비와 배포 대기는 별도다.

## 범위와 완료 조건
- 기존 사찰 체험판은 유지하고 방문 세션·위치·동작만 별도의 상시 Worker/D1 서버에 연결한다.
- 같은 채널에서 이동·참배·명상·법복·12지신 얼굴을 표시한다. 접속·퇴장·재접속과 개인 공간 격리를 확인한다.
- 실제 3명일 때 기존 목표에 따라 가상 방문객은 17명이다. 기존 채널 3개·정원 20명을 유지한다. 이번 실제 검수 인원은 3명이다.
- 신청·시험 아이템·개인 공간 배치는 기존 브라우저별 저장 방식이다. 가격·결제·실제 계정 인증은 변경하지 않는다.
- 세션 키는 메모리에만 두며 서버에는 해시를 보관한다. 현재 위치/동작만 덮어쓰고 30초 무응답 세션은 표시에서 제외한다. 만료 행은 다음 입장 때 삭제한다.

## 구현
- `src/shared-presence-transport.ts`: 채널 join/move/leave만 별도 서버로 전달한다. 기타 API와 거래는 기존 로컬 시험 처리다.
- 공통 `review-presence.ts`: 개별 세션 키 전송과 계정 전환 시 이전 방문 세션 정리를 연결했다. 기존 쿠키 기반 로컬 서버와 키가 없는 응답도 계속 지원한다.
- 공유 서버 소스: 별도 `sasa-presence-service` 작업 디렉터리. D1 스키마와 Worker, SQLite 기반 상태/권한 검사가 있다. 임시 인터넷 터널이나 Mac API를 사용하지 않는다.
- 익명 방문자는 로그인 없이 함께 탐방한다. 회원 전용 수행의 시험 로그인 정책은 유지한다.

## 검수
- 서버: 3개 독립 세션의 상호 상태, 역순 이동, 위조 키 거부, 퇴장 뒤 재사용 거부, 정원, 채널 분리, TTL, 출처 및 좌표 검증. 분리해서 불러온 Worker도 같은 DB 상태를 읽는다.
- 로컬 프런트 + 실제 인터넷 백엔드: 독립 Chrome 실행 3개에서 각각 다른 두 캐릭터, 이동, 토끼 얼굴·법복, 실제 참배, 개인 공간 진입/귀환, 퇴장과 새로고침 재접속을 통과했다.
- 첫 시도에서 한 브라우저 내부의 복수 컨텍스트가 입장 렌더링을 마치지 못했다. 실제 3대 기기 조건에 가깝게 독립 Chrome 실행을 사용하고 각 창을 활성화해 재검수했다. 앱의 숨김 렌더링 중지 조건은 바꾸지 않았다.
- 최종 공개 프런트 검수 결과와 배포 버전은 evidence/shared-visitors/published 및 publication.json에 기록한다. 3명의 실제 사람이 참가한 평가와 운영 50명 부하 시험은 아니다.

## 최종 공개 검수

기존 공개 주소의 체험판 v40과 별도 공유 서버 v1을 배포했다. 이 Mac의 로컬 미리보기 서버를 종료한 뒤 공개 HTTPS 주소만으로 독립 Chrome 3개를 실행했다. 각각 다른 두 실제 세션의 모델·이동·토끼 얼굴·법복·참배를 확인했다. 개인 공간에서 사찰 캐릭터가 사라지고 귀환 때 재입장하며, 브라우저 종료·새로고침 후 인원과 캐릭터가 정리됐다. 실제 3세션 조건에서 가상 방문객은 17명이었다. 화면 예외와 공유 API의 실패 응답은 0건이다.

창을 입장 응답 직후 바로 닫으면 퇴장 키가 아직 전달되지 않았을 수 있다. 이 경우 무응답 TTL 30초 및 다음 조회 시간을 포함해 최대 45초를 허용하는 검수로 구분했다. 정상 퇴장 요청과 TTL 정리를 혼동하지 않는다. 기본 아이콘 관련 404 콘솔 메시지는 별도로 관찰됐으며 화면 예외/공유 API 오류 0건이라는 결과를 전체 사이트의 모든 HTTP 요청 성공으로 확대하지 않는다.

본 서비스 110개, 체험판 49개, 공유 서버 3개 자동 검사를 통과했다. 양쪽 웹 빌드 및 42개 정적 에셋 기록 검사도 통과했다. Cloudflare D1 스키마가 실제 배포에 적용됐고 익명 키로 세션 생성/삭제가 동작함을 확인했다. 검수 증거는 `evidence/shared-visitors/summary.json`, `published/result.json`, `publication.json`이다.

친구 3명은 기존 체험판 링크를 각자 다른 기기/브라우저에서 열고 같은 채널(기본 1채널)로 입장하면 된다. ChatGPT 계정과 서버 실행용 Mac은 필요하지 않다. 108배 등 기존 회원 전용 체험은 각 브라우저의 시험 로그인 동선을 계속 사용한다. 공유된 것은 캐릭터 방문 상태이며 시험 아이템·개인 방 배치는 브라우저별이다.
