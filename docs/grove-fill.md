# 종류별 군락 보강과 비질 스님 주변 단풍

## Milestone · M2 공간 보완 / M4 웹 검수
목표는 단풍과 대나무 군락을 구분한 채 적절히 보강하고, 비질 스님 뒤와 양옆에 단풍이 풍성하게 보이게 하는 것이다. 목표 날짜와 새 Issue는 만들지 않는다.

## Epic · 기존 E01 공간 구성(#1), E04 웹 검수(#4)
포함: 단풍8그루·대나무4무리 추가, 스님 주변 단풍5그루의 느슨한 반원 군락. 나머지 단풍은 북쪽2그루·극락전 주변1그루. 대나무는 기존4군락에 각각1무리. 제외: 스님 위치·행동/음성, 건물·길·연못·조명·판매 자리, 기존 나무 재질/거리별 간소화 변경.

## Implementation Issue 후속
- 기존 #18·#23(M2): 식재33→45(계절나무16→24, 대나무17→21), 8→9군락. 스님 정면과 중앙 뒤뜰, 산책로·전각 진입을 비우고 두 수종 사이 최소5m의 줄기 기준 거리를 둔다. 선행: 사용자 군락 보강 승인. 완료 조건: 스님 주변5그루 단풍 배경·종류별 구분·기존 모델/계절/거리별 재사용 유지. 검증: 같은 각도 전후와 배치 여유 검사. 예상 S.
- 기존 #64·#66·#77(M4): 실제 보행·스님 인사·PC/터치·물리 식재 좌표·슬롯 보존·공개 체험판 검수. 선행: 위 보강. 완료 조건: 나무가 보행이나 스님과의 상호작용을 막지 않고 전체 식재45개가 누락 없이 표시된다. 예상 S. 예비 시간·배포 대기는 별도이며 Epic에 중복 합산하지 않는다.

기존 나무의 좌표·크기/형태/색과 인스턴스 프로토타입을 유지하고, 추가 나무도 같은 모델과 거리별 공유 방식으로 렌더링한다. 스님 발치의 기존 비질 낙엽 연출과 새 군락 바닥 표현을 함께 사용한다. 보조등은 기존16개 위치와60cm 크기를 유지한다.

## 검수 결과
원본83개·독립 체험판19개 단위 검사와 타입·빌드 통과. 실제 약215m 산책과 네 전각 참배 확인. PC/터치에서45개 물리 식재 위치·24개 계절나무 공유 인스턴스·스님 인사 말풍선·클릭 보행을 확인했다. 531개 전체 판매 자리 기록 보존, 기존 보조등16개 유지. 오류·에셋 실패·실제 API 요청 없음. 실기기 성능 판정을 새로 한 것은 아니다.

검수 자료는 evidence/grove-fill/. 재현은 독립 체험판 scripts/check-grove-fill.mjs, check-grove-fill-views.mjs, check-woodland-walk.mjs.
