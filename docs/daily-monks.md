# 생활 스님 네 명 추가

사용자 승인: 연못 돌보기·인등전 정돈·화초 물주기·경전 읽기 네 역할 모두 구현. 이후 제안한 동전 카메라·개인 공간 풍경·해태상·공동 모금 시설은 의견만 전달했으며 이번 구현에 포함하지 않는다.

## 기존 작업 대응

- M2 / Epic #1 / Implementation #23: 연못·산책길 주변 생활 스님 3명과 작은 독서 마루·화분 소품. #22 후속으로 인등전 스님 1명. 기존 사람형·법복·목재·조명과 보행 동작 재사용. 신규 이슈·Milestone·날짜를 만들지 않는다.
- M2 / Epic #1 / #15: 스님과 전용 독서 마루·화분의 보행 충돌, 몸체 클릭/터치가 이동으로 중복 처리되지 않도록 연결.
- M3 / Epic #1 / #36: 스님을 6.5m 안에서 클릭/터치하면 짧게 합장하고 하던 일을 이어감. 새 수행 보상·상점·음성·퀘스트·결제 없음.
- M4 / Epic #1 / #64 및 Epic #4 / #66 후속: 배치·실제 동작·PC/터치·개인 공간 숨김/복귀·오류 검사. 예상 작업량 M, 검수 실행과 배포 대기는 별도이며 Epic에 중복 가산하지 않는다.

## 배치와 동작

- 연못 북서쪽의 비어 있는 북쪽 물가: 동전 던지기 U자 구간과 3.4m 이상 간격. 작은 그릇에서 먹이를 집어 실제 물 안쪽으로 던지고, 두 관찰 지점 사이를 천천히 이동한다.
- 인등전 등 선반 앞: 기존 12개 판매 자리·선반·점등 상태를 바꾸지 않는다. 천으로 선반 앞을 닦고 가까운 다음 자리로 이동하며 등을 살핀다.
- 뒤편 두 전각 사이 화단: 나무 앞쪽의 작은 화분 줄을 따라 물뿌리개로 물을 준다. 기존 산책로와 출입구를 비워둔다.
- 서쪽 뒤 산책길 옆: 작은 나무 마루와 방석에 가부좌로 앉아 경전을 읽는다. 책장을 넘기고 가끔 주변을 바라본다.

공용 사람형 NPC는 기존 5명에서 9명으로 증가한다. 실제 접속자·AI 방문객 수와 별도로 관리한다. 기존 스님·강아지·사용자 좌석·상품 배치·중앙 마당·가격·결제는 유지한다.

## 완료 조건과 검증

- 각 역할의 손·소품 동작과 독립 주기. 경로 끝에서 일하고 회전한 뒤 이동하며 순간 이동하지 않음. 방문자가 가까우면 이동만 양보하고 생활 동작은 유지.
- 클릭/터치 합장 1회 후 같은 활동 시간에서 복귀. 드래그·먼 거리·가림·열린 대화창은 합장 시작으로 처리하지 않음.
- 물·나무·판매 자리·동전 구간·산책길과 간섭 없음. 개인 공간 진입 시 스님·소품·물방울·말풍선을 숨기고 복귀 시 복원.
- 새 광원·그림자 맵·외부 모델·추가 서버 요청·상시 타이머 없음. 기존 렌더 루프를 쓰고, 숨긴 페이지·개인 공간에서는 정지, 먼 거리에서는 생활 주기 갱신을 중단하고 모델을 숨김. 넓은 배치도에서는 정지 자세로 표시.
- 단위 검사로 4개 경로의 지면·나무·동전 경계·인등 슬롯 간격, 속도·연속성과 합장 시작/종료를 검사. 실제 Chrome PC/터치에서 네 몸체를 클릭하고 동작·복귀와 개인 공간 분리를 검수한다.

검수 도구: tests/daily-monks.test.ts, scripts/check-daily-monks.mjs. 증거: evidence/daily-monks. 실휴대폰·50명 부하 검수로 간주하지 않는다.

화면 검수 중 기존 Quick Tunnel이 `Unauthorized: Tunnel not found` 상태로 재시도만 하던 것을 확인했다. 만료된 통로를 새로 만들고 기존 체험판의 Colyseus 연결 주소를 갱신한다. 통로는 임시 주소이며 Mac 전원과 인터넷이 필요하다.

최종 결과: 원본 113개·체험판51개 단위 검사와 양쪽 빌드 통과. 공개 Sites v43에서 네 스님 각각 PC/터치 인사·동작 재개, 개인 공간 숨김·복귀 통과. 새 임시 통로의 독립 브라우저3개로 1→2→3명 표시와 단절 복구 통과. 실제 참가자 평가·실휴대폰·대규모 성능 측정과 구분한다. 영수증은 evidence/daily-monks/publication.json에 기록했다.
