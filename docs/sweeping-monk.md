# 뒤뜰 비질 스님

2026-11-11 사용자 승인: 대웅전 뒤 산책길의 스님 한 명, 클릭 시 합장·말풍선과 중저음 한국어 인사 후 비질 재개. 별도 이용권·구매·로그인을 요구하지 않는다.

- **Milestone M2 · Epic E01 #1 · Implementation #23 후속:** 뒤뜰 산책길 남쪽 가장자리 (-21, 70.8)에 스님·대나무 빗자루·낙엽을 배치. 길 중앙을 비우고 스님의 몸은 통과하지 않도록 한다. 기존 얼굴·법복을 재사용하며 대웅전 스님은 바꾸지 않는다.
- **Milestone M3 · Epic E01 #1 · Implementation #36 후속:** 비질 → 빗자루 옆에 세우기 → 유저를 향해 합장 → “나무관세음보살~” 말풍선·중저음 음성 → 비질 복귀. 동작·음성 중복 시작을 차단하고 화면 이탈·개인 공간 진입 시 중지한다. 기존 종교 감수 대기 상태는 유지한다.
- **완료 조건:** 실제 스님 메시 클릭과 키보드로 접근 가능한 인사 버튼이 같은 동작을 실행. 가까운 거리에서만 인사하며 음성은 전체 무음·음량을 따른다. 홈페이지 로딩 시 자동 발화하지 않는다.
- **선행:** 기존 산책길, 스님/방문자 모델·법복, 공통 소리 설정. 외부 서비스 설정과 정책 결정은 필요하지 않음.
- **검증:** `tests/sweeping-monk.test.ts`, `scripts/check-sweeping-monk.mjs`, 실제 캔버스와 재생 음성을 함께 기록한 `evidence/sweeping-monk/greeting.webm`. 음성 파일·출처는 에셋 검사에 등록한다.
- **예상 작업량:** 이번 추가 범위 S. 외부 대기·감수·예비 시간은 제외하며 기존 Epic·Milestone 작업량에 중복 합산하지 않는다. 목표 날짜는 미설정. 새로운 GitHub 이슈는 만들지 않는다.

미리보기의 공간 둘러보기에서 **뒤뜰 · 낙엽 쓸고 있는 스님**을 고르면 가까운 시점으로 볼 수 있다. 실제 산책에서도 같은 위치에 있는 스님을 클릭할 수 있다. 음성은 기존에 승인된 Reed 한국어 남자 음성으로 로컬 합성한 약 2.9초의 검수용 파일이다. 말풍선·인사 버튼·공간 선택은 현재 14개 UI 언어에 연결했으며 음성은 요청한 한국어 구절을 유지한다.
