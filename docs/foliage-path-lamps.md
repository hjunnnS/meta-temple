# 단풍·대나무 사진 반영과 산책로 야간등

## Milestone · M2 공간 보완 / M4 체험 검수
사용자 첨부 1~3의 잎이 겹친 단풍 수관, 첨부 5~6의 가는 잎가지·마디가 있는 대나무, 첨부 4의 낮은 사각 야간등을 반영한다. 목표 날짜와 신규 GitHub Issue를 추가하지 않는다.

## Epic · E01 공간 구성(#1), E04 웹 검수(#4)
포함: 기존 군락의 나무·대나무 모양 보완, 대웅전 뒤 산책길의 낮은 사각 등. 제외: 건물·불상·길·판매 자리·아이템 재질/가격/정책 변경, 사찰 밖 나무 복원, 고밀도 새 식재.

## Implementation Issue 후속
- 기존 M2 #18·#23·#25: 같은 식재 위치에서 단풍의 접힌 다엽 윤곽, 대나무의 마디와 5단 잎가지, 14m 기준 간격의 낮은 사각 등 16개. 선행: 사용자 사진과 보완 승인. 완료 조건: 나무 수·군락 보존, 길/전각 입구/벽 여유, 낮·밤 밝기 전환. 검증: 같은 각도 전후 및 단위 검사. 예상 M.
- 기존 M4 #64·#66·#77: 산책길 보행·전각 진입과 고정 판매 자리 보존·조명 수/거리별 나무 표현·공개 체험판 확인. 선행: 위 보완. 완료 조건: 보행 장애·시각 오류·에셋 실패가 없고 개별 야간등의 그림자 맵을 추가하지 않는다. 예상 S. 예비 시간·배포 대기는 별도이며 Epic에 작업량을 중복 합산하지 않는다.

## 리소스와 배치
33개 대상 식재(대나무17무리·계절나무16그루), 8개 군락을 유지한다. 가을·봄 잎은 불투명 기하를 공유하고, 기존 28m/70m 거리 경계에서 세 단계로 줄인다. 겨울 눈 수관과 3~5월 봄꽃/6~11월 단풍/12~2월 눈 계절 구분은 유지한다. 대나무 6개 줄기/무리 유지, 잎폭을 좁히고 가지를 3→5단으로 보완한다.

등 높이 약 0.75m, 옆길에서 2.05m 이격, 실제 등 사이 최소 10m. 산책로/전각 출입로는 최소 1.7m 비우고 나무/벽 여유도 검사한다. 공유 발광창과 바닥 빛 번짐, 가까운 두 개의 그림자 없는 실제 광원만 사용한다. 낮에는 꺼지고 해질녘·밤에 켜진다.

## 검수
원본 84개·독립 체험판 20개 단위 검사와 타입·빌드 검사 통과. 실제 약 215m 산책과 네 전각 참배, PC·터치 화면에서 조명 낮/밤 전환·16개 등·실제 주변 광원 최대2개/추가 그림자맵 없음 확인. 531개 전체 판매 자리 기록 보존. 동일 장면 정점수 2,610,489→2,672,649(약2.4% 증가), 나무/대나무 수량은 그대로다. 이 수치는 정점 수 비교이며 FPS·모바일 실기기 성능을 새로 승인한 것은 아니다.

재현 스크립트는 독립 체험판 체크아웃의 scripts/check-foliage-views.mjs, check-foliage-lamps.mjs, check-woodland-walk.mjs에 있다. evidence/foliage-lamps/에 전후 화면과 실제 보행·조명 검사 결과를 저장한다.

## 체험판 반영
공개 체험판 v13 반영 완료. 공개 URL PC·터치 화면에서 새 잎/대나무 재질·16개 야간등·낮/밤 전환·최대2개 실제 광원·네 전각 참배를 확인했다. 페이지 오류·에셋 실패·실제 API 요청 없음. GitHub 커밋·푸시는 이번 요청 범위에 포함하지 않았다.
