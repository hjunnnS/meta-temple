## 재현

이 Mac에서 `npm run candidate:local`을 켠 뒤 `sh scripts/check-local-expansion.sh`를 실행한다. 외부 계정·메일·결제·호스팅이 필요하지 않다. Chrome·Playwright와 로컬 PostgreSQL을 사용한다. 전체 증거는 `evidence/local-expansion/`, 개인 공간 기존 회귀 검사는 `evidence/private-room/`, `evidence/private-display/`, `evidence/private-practice/`에 기록한다.

실제 웹 성능의 원본은 `evidence/local-expansion/performance/`, 개인 공간 반복 출입은 `private-performance.json`, 이용권 보안은 `security.json`, 새 스냅숏 복원은 `recovery.json`, 14개 언어 통합은 `integration-locales.json`, 미리 생성된 쉼터 번역은 `shelter-locales.json`을 따른다. 벤치마크 결과는 검사 종료 후 별도로 기록한다.

## 확정된 기능 검사 결과

- 자동 검사 61개·에셋 무결성·타입 검사·빌드 통과.
- 이용권: 로그인·결제 전 차단, 중복 주문/결제, 취소, 타인 접근, Origin, 상품 버전/금액 조작, 권한 회수·계정 삭제·로그아웃 차단 통과. 삭제 시 개인 배치를 정리하고 미결제 시험 주문을 취소했다.
- 주문 응답을 지연한 상태에서 닫고 재열기, 결제 서버 처리 후 응답 유실, 한 건의 결제 권한 복구를 실제 브라우저로 확인했다. `access-recovery.json`.
- 다섯 아이템의 구매·배치·교체·삭제·저장·페이지 재방문·잘못된 자리/상품/버전 차단과 원래 사찰 설치 유지 통과. 기존 `evidence/private-display/check.json`.
- 절하기·명상 종료·이동·Escape·전시창 전환·재입장 초기화·공용 공간에 동작 미전송 통과. 기존 `evidence/private-practice/check.json`.
- 14개 언어의 시험 주문·재방문·명상·전시창과 키보드 초점, 미리 생성된 쉼터 메뉴 번역 검사 통과. 원어민 표현·종교 감수 완료를 뜻하지 않는다.
- 별도 DB에 새 스냅숏을 복원해 19개 테이블 지문과 시험 이용권, 다섯 전시 위치·revision=7·원래 설치 5개를 대조했다. 검수용 DB·스냅숏·시험 데이터는 정리했다.
- 최종 후보의 개인 공간을 10회 출입하고 60초 명상했다. 평균 60.00 FPS, 하위 1% 54.57 FPS. 예열·GC 후 JS 힙 증가는 약 2.48 MiB였다. GPU·전체 프로세스 메모리 수치는 아니다.
- 20 Mbps·80ms 로컬 후보에서 첫 3D 프레임은 최초 7.26초, 캐시 재방문 2.90초로 기존 15초·5초 기준 이내다. 연꽃 클릭 이후 입장 연출을 포함한 걷기 준비 시간과 첫 3D 프레임은 원본에서 별도로 기록한다.
