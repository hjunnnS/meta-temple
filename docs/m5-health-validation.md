# M5 #79~#82 건강 코스 검수

2026-11-13. 기존 Epic #1 / Milestone #5. 자유 탐방·고민 선택·이전/다음·건너뛰기·종료, 3D 가이드 스님·말풍선·Reed 임시 음성, 지도 목적지 강조·실내 도착 판정, 기존 참배/명상/108배/예약 연결을 구현했다. 기존 공간·캐릭터 품질·거래 규칙을 재사용한다.

검수 근거:
- evidence/m5-health: 실제 건강 코스·참배 동작, 비회원 108배 로그인 복귀, 한 번 절하기로 108배가 완료되지 않는 것, 구매 없이 종료.
- evidence/m5-offering: 실제 참배·10초 이상 명상·선택한 연등 자리→예약 시 로그인→시험 결제/설치→안내 완료. 자리 번호 보존.
- evidence/m5-108: 실제 동작/카운트 루프를 108번 실행하고 1~107회에서는 다음 안내가 잠겨 있으며 108회 서버 응답으로만 수행 완료가 되는 것. 이 검사만 렌더 프레임의 시계를 100ms로 가속했으며 API·횟수 응답을 대체하지 않았다. 보통 속도 동작/첫 회 기록은 별도 검사했다.
- evidence/m5-edge: PC·터치 자유 탐방, 안내 재실행/이전/종료 후 클릭 보행, 실제 음원 재생·빠른 다시 듣기 후 단일 음성 유지·종료 시 음성 정지, 로그인 취소 후 안내 종료.
- 순수 함수 검수: 바닥 높이가 다른 외부 위치·먼 지점·잘못된 좌표는 도착으로 인정하지 않는다. 이전 단계 이벤트는 새 단계 결과를 바꾸지 않는다.

시험 음성은 이미 사용한 macOS Reed 한국어 중저음 음성으로 로컬 생성했다. 외국어는 자막을 기본으로 제공한다. 정식 종교 감수·처음 온 참가자 평가는 실제 완료한 것으로 표시하지 않는다. 진행은 방문 중 메모리에만 있으며 고민/수행 이력은 새 API나 분석 로그에 전송하지 않는다.

사용자는 건강 코스 화면/완료 화면을 확인하고 가족→관음전, 시험→문수전, 관계→보현전, 상실→지장전의 시험 확장을 승인했다. 이로써 #83의 해당 선행 조건을 충족했다. 정식 종교 감수는 후속으로 유지한다.
