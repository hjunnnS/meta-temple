# 한지 연등 단일 재질 검수 01

2026-11-06 / M1 I01 #5 / PR #73

사용자 승인 범위는 연등 한 개의 재질·형태 검수다. 기존 사찰 장면, 연등 밀도, 전체 맵은 변경하지 않았다.

## 실행

`npm run dev` 후 `/hanji.html`. 낮/밤, 5색, 근접/전체 보기, 드래그 회전 지원. 프로덕션 빌드도 index.html과 hanji.html 두 진입점을 포함한다.

## 구성

- 팔각의 몸통과 접힌 상하부를 각각 별도 종이 면으로 만든 열린 껍질 구조.
- 가는 내부 골조와 면 가장자리 접힘, 밀리미터 규모의 불균일한 종이 장력 주름.
- 한지 섬유 텍스처로 표면 밝기·미세 법선·빛을 가리는 밀도를 계산하는 전용 셰이더. 밤에는 내부 광원과 면 사이 거리, 섬유 밀도, 겹침선에 따라 투과광 차이를 표현.
- 실측 광학값에 근거한 시뮬레이션이나 실물 스캔이 아니라 시각 검토용 근사 모델이다. 실사 수준 달성 또는 최종 시각 승인으로 처리하지 않는다.

## 자산

`public/textures/hanji-fibres-generated-v1.png`: 이번 작업에서 이미지 생성 도구로 만든 한지 표면용 합성 텍스처. 실제 사진 스캔이라고 표시하지 않는다. 사용자 사진 원본/인물을 자산으로 복제하지 않았다. 기존 Poly Haven 재질과 출처를 구분한다.

## 검증

기존 테스트 10개·타입 검사·두 페이지 생산용 빌드 통과. 실제 브라우저에서 셰이더 렌더링, 낮/밤, 레드/핑크 변경, 근접/전체 보기 및 드래그 회전 확인.

화면: evidence/hanji-study-01-close.png, hanji-study-01-night-close.png, hanji-study-01-pink-night.png.
새 단일 연등을 기존 전체 장면에 적용하지 않았으며 성능 합격 측정도 미수행. 공통 번들 크기 경고는 유지한다.

## 검수 02 — 2026-11-06

사용자 피드백: 두꺼운 종이 상자처럼 보임. 얇은 한지가 골조에 붙은 느낌, 낮의 은은한 점등과 밤의 강한 점등 요구.

- 면의 미세 처짐과 장력 주름을 보강하고 섬유 요철 강도를 낮춰 거친 두꺼운 표면을 완화.
- 얇은 종이 너머의 내부 골조 그림자·접착 겹침선 표현. 광학 스캔/실측 기반이 아닌 시각적 근사다.
- 낮에도 내부 광원을 유지하고 밤의 광원 기여를 더 크게 설정. 거리 감쇠에 따라 중심과 가장자리의 밝기를 구분하며 색상별 하이라이트 압축으로 백색 클리핑 방지.
- 밤에 실루엣 밖으로 번지는 부드러운 빛 추가. 기존 사찰 장면과 전체 배치 미변경.
- 테스트 10개·타입/두 페이지 빌드 통과. 실제 브라우저에서 동일 레드/동일 시점의 낮·밤을 비교. 증거: evidence/hanji-study-02-day.png 및 hanji-study-02-night.png.
- 실사 수준 충족이나 사용자 시각 승인을 선언하지 않는다.

## 검수 03 — 2026-11-06

- M1 / I01(#5) 대표 공간 시각 검증의 하위 재질 개선 작업. 기존 Issue와 사용자 시각 승인 대기를 유지한다.
- 각진 상·중·하 3단 면을 제거하고, 휘어진 8개 골조 사이에 연속된 얇은 종이 면을 연결했다. 열린 상하부, 가는 테두리, 장력 주름으로 상자 형태를 완화했다.
- 내부 광원의 거리와 관찰 방향, 종이 밀도 및 염료별 흡수를 사용해 투과광을 계산한다. 섬유 뭉침·접착 겹침·골조 뒤는 빛을 더 가리며, 중앙은 따뜻하게 빛나고 주변은 염색색을 유지한다.
- 내부 등 켜기/끄기 비교 기능을 추가했다. 낮에는 은은한 투과광, 밤에는 더 강한 내부광을 사용하며 하이라이트를 압축한다.
- 실제 브라우저에서 동일 레드/동일 시점의 낮·밤·밤 소등 상태 확인. evidence/hanji-study-03-day.png, hanji-study-03-night.png, hanji-study-03-night-off.png.
- 실측 한지 광학값을 재현한 물리 시뮬레이션은 아니며 시각적 근사다. 사용자 시각 승인 전으로 유지한다. 한 개의 검수 화면만 수정하며 전체 사찰 배치는 변경하지 않았다.
