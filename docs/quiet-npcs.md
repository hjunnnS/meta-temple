# 상시 안내 스님과 생활 스님 두 명

사용자 승인: 천왕문 근처 안내 스님을 상시 배치하고 실제 클릭으로 고민별 안내를 시작한다. 앞서 제안한 두 역할도 스님으로 추가한다. 가격·결제·운영 정책 변경 없음. 기존 건물·아이템·슬롯·지도 22곳·사용자 좌석·기존 독경/비질 스님·강아지 유지.

## Milestone·Epic·Implementation 대응

- M5 / Epic #1 / 기존 #80·#79 후속: 안내 스님을 천왕문 진입부 동쪽 가장자리 고정 위치(1.6, 0.09, -59)에 배치. 자유 탐방·안내 이동·도착·안내 종료 때 사라지거나 목적지로 이동하지 않는다. 실제 몸체 클릭/터치 또는 머리 위 안내 버튼으로 다섯 고민 선택을 연다. 비회원도 이용 가능. 개인 공간에서는 공용 NPC를 숨기고 사찰 복귀 시 복원. 선행: 기존 가이드 코스. 완료 조건: 코스 전후 동일 위치·활성 상태, 실제 선택 화면 진입, 기존 안내 단계/도착 판정 보존. 예상 S.
- M2 / Epic #1 / 기존 #23의 쉼터·명상숲 후속 범위: 차 마시는 스님 1명과 포행 스님 1명 추가. 새 GitHub 번호를 만들거나 기존 Issue 제목·상태·승인 이력을 바꾸지 않는다. 사용자 요청으로 확장한 배치 범위이며 원래 Issue의 미구현으로 소급하지 않는다. 예상 S, 두 NPC를 별도 Epic/Milestone 작업량으로 중복 가산하지 않음.
  - 차 스님: 쉼터 서쪽 옆마당의 전용 작은 탁자. 기존 사용자 좌석 20개를 그대로 유지. 기존 아바타/법복/찻잔·마시는 동작, 기존 목재 재질 재사용. 주기적으로 차를 마시고 나머지 시간에는 앉아 쉼. 별도 음성·상점·퀘스트·이름표 없음.
  - 포행 스님: 대웅전 뒤 산책길 북쪽 가장자리, X=-12~9 / Z=74.1 구간을 초속 0.4m로 왕복. 양 끝에서 5초 쉬며 방향 전환·합장. 이용자가 1.6m 안에 오면 멈추고 멀어지면 이어서 이동. 전각 출입구·중앙 마당은 비워 둠.
- M2 / Epic #1 / #15 후속: 새 NPC/전용 탁자의 실제 위치를 보행 충돌 판정에 연결. 중앙 진입로와 기존 좌석을 막지 않으며, 포행 스님의 충돌 위치도 현재 위치를 사용. 선행: 배치/기존 보행. 완료: 기존 포인트 이동 유지, 접근 시 양보·이탈 시 재개 확인. 위 배치 작업량에 포함.
- M4 / Epic #1 / #64 후속 검수: PC·터치의 NPC 클릭/코스 시작·종료, 새 동작, 개인 공간 왕복과 기존 다섯 UI 개선 회귀를 확인. 검수 대기는 구현량에 중복 합산하지 않음.

## 구현 원칙

사찰 공용 공간의 사람형 NPC는 총 5명(대웅전·비질·안내·차·포행), 강아지 1마리는 별도다. 불·보살상과 사천왕상, 연못 잉어, 실제 방문자는 이 수에 포함하지 않는다. 새 NPC를 실시간 접속자나 계정으로 등록하지 않는다. 공용 NPC는 개인 공간 안에 들어오지 않는다.

새 광원·그림자 맵·외부 모델/음원·서버 요청·상시 타이머 없음. 기존 그림자 맵과 렌더 루프를 사용한다. 숨긴 페이지/개인 공간에서는 생활 동작을 정지하고 먼 거리에서는 동작 갱신을 줄인다. 기존 반짝임 완화 설정에서도 포행 중 다리 동작을 유지해 미끄러지는 모양을 피한다.

## 검수 결과

- 원본 97/97, 독립 체험판 34/34 자동 검사, 두 소스 타입 검사·빌드 통과. 새 검사는 건조한 배치, 기존 좌석·탁자와 간격, 포행 경로/속도/정지/연속성, 찻잔 동작의 부드러운 주기를 확인.
- 실제 Chrome PC 1280×900 / 터치 모드 390×844에서 안내 스님 몸체를 클릭/터치하여 5개 고민 선택 화면 진입. 자유 탐방·건강 코스 시작/이동/도착/마침 전후에 안내 스님 위치와 활성 상태 유지.
- 기존 사용자 좌석에 실제로 앉았다 일어날 수 있고 차 스님과 겹치지 않음 확인. 찻잔이 입 쪽으로 올라갔다 내려오는 동작, 산책길 가장자리의 포행 이동을 실제 장면에서 확인.
- 실제 키보드 이동으로 포행 스님에게 다가가 정지, 멀어져 재개 확인. 기존 포인트 이동도 통과.
- 개인 공간 진입 시 공용 NPC 숨김, 사찰 복귀 후 안내·차·포행 NPC 복원 및 장면 수 1개로 정리 확인.
- 기존 UI 1~5의 PC/터치 회귀 통과. 이전 증빙은 보존하고 이번 결과만 regression 폴더에 분리.

증빙: evidence/quiet-npcs/check.json, life.json, regression/ux-check.json 및 PC/터치 화면. 터치는 브라우저 모드이며 실휴대폰/Safari/운영 다인 부하를 새로 검수한 것으로 간주하지 않는다. 기존 큰 번들 안내는 남아 있다.
