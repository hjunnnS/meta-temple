# 가장자리 정원과 산책 경관 보완

## Milestone
기존 M2 공간 구성 보완·M4 웹 검수. 넓은 중앙마당과 기존 건축·아이템을 유지하면서 건물 뒤와 담장 옆 남는 땅을 정원으로 연결한다. 목표 날짜 없음.

## Epic
E01(#1) 공간 구성과 E04(#4) 검수 후속. 포함: 종류별 군락 보강, 저층 식재 띠, 연못·쉼터 경관 연결, 산책길 굽은 구간의 시야 구성. 제외: 건물·판매 슬롯·가격·구매 흐름·조명·캐릭터·나무 모델 품질 변경, 중앙마당 축소. 새 이슈 생성 없음.

## Implementation Issue 대응
- 기존 #18·#23(M2): 건물 뒤 군락 → 담장 노출 완화 → 연못/쉼터 연결 → 산책길 경관 순서로 구현. 선행: 사용자 조경 진행 승인. 완료 조건: 단풍·대나무 군락 분리, 중앙 통경 유지, 전각·좌석·동전 접근 방해 없음. 검증: 위치 간격 검사·같은 시점 전후 화면·실제 보행. 예상 S.
- 기존 #64·#66·#77(M4): PC/터치 보행, 다섯 아이템 신청·개인 공간·수행 회귀, 낮밤 성능 측정, 체험판 반영. 선행: 위 조경 완료. 완료 조건: 기존 품질·531자리 데이터 보존과 통합 검수 통과. 예상 S. 대기는 작업량과 별도.

## 구성
기존 45곳에서 74곳으로 식재를 보강한다. 계절나무 41그루는 기존 공유 모델·거리별 상세도·근거리 그림자를, 대나무 33무리는 기존 정적 재질별 배치를 재사용한다. 중앙마당, 건물, 판매 아이템과 길의 좌표는 변경하지 않는다. 14개 지피 식재 구역과 낮은 관목은 기존 정적 배치로 합친다. 연못 동전 투척 구간에는 새 장애물을 두지 않는다.

## 검수 결과
원본 85개·체험판 21개 단위 검사, 타입 검사와 빌드 통과. 실제 장면에서 74개 식재 위치와 공유 계절나무 41개를 확인했다. PC/터치 클릭 보행·비질 스님 인사, 다섯 아이템 신청·로그인 후 복귀·절하기·개인 공간 저장·일정·야간 회귀 통과. 새 식재의 전각·산책길·좌석·동전 구간 간격 검사 통과. 기존 공개 v17 대비 건물 배치·531개 슬롯·한지·나무 모델·장면 코드가 동일함을 해시 검사했다.

이 Mac Chrome, 1280×720, 낮밤 각각 30초 보행 측정에서 평균 60FPS, 1% 느린 프레임 기준 약 50FPS. 전체 기기 성능 보장을 의미하지 않는 국소 회귀 검사다. 정적 조경은 12개 재질 배치, 114,327정점으로 합쳐져 있으며 추가 조경 자체의 상세 그림자 캐스터는 없다. 계절나무 근거리 그림자는 기존 방식 유지. 전후 비교는 별도 공개 v17 복사본과 수정본을 같은 각도로 촬영했다.
