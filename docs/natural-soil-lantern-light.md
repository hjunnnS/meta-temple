# 자연스러운 흙길과 연등 야간 빛

## Milestone
기존 M2 공간 표현 보완, M4 웹 검수. 목표 날짜 없음.

## Epic
기존 E01(#1) 공간 구성, E04(#4) 웹 검수. 포함은 흙길의 부드러운 경계·불규칙한 폭·자연스러운 갈림길, 연등의 밤 빛 번짐과 따뜻한 바닥 반사광이다. 제외는 돌길·중앙 마당 재질, 지형 높이·보행 흔들림, 연등 한지/골조/염료/소유자 LED와 판매 자리 변경이다.

## Implementation Issue 후속
- 기존 #18·#23·#25(M2): 기존 흙길 중심선을 유지하며 하나의 공유 마스크로 경계와 갈림길을 표현한다. 연등은 밤에만 색별 공유 후광5배치와 바닥 빛1배치를 더한다. 선행은 사용자 적용 승인. 완료 조건은 흙길이 주변 흙으로 부드럽게 이어지고, 낮 연등과 한지 질감·내 연등 반짝임은 유지되는 것이다. 검증은 같은 각도 낮밤 전후·보행·돌길/중앙 마당 제외·조명 상태 확인. 예상 M.
- 기존 #64·#66·#77(M4): 531개 슬롯 전체 기록·보행·낮밤 전환·공개 체험판 검수. 선행은 위 표현 보완. 완료 조건은 추가 실제 광원/그림자맵 없이 적용되고 UI/접수·이동에 간섭하지 않는 것이다. 예상 S. 예비 시간·배포 대기는 별도. 새 Issue/승인 상태 변경 없음.

## 표현 방식
흙길은 높이0.025m의 시각적 마스크이며 실제 보행 바닥을 바꾸지 않는다. 기존 길 중심선, 계단과 건물 위치도 유지한다. 하나의 경로 합집합 마스크로 길이 만나는 곳의 겹침 줄무늬를 방지한다. 돌길과 중앙 마당·연못/경계 밖은 마스크에서 제외한다.
연등은 기존 한지 셰이더를 수정하지 않는다. 440개 등에 각각 광원을 붙이지 않고 인스턴스 후광과 공유 바닥 빛을 사용한다. 낮에는 둘 다 비활성, 해질녘은 약하게, 밤에 활성화한다. 장식 연등도 같은 표현을 적용한다. 소유자 LED·이름표·고정 슬롯은 유지한다.

## 검수 결과
원본83개·독립 체험판19개 단위 검사 및 타입·빌드 통과. 531개 전체 슬롯 기록과 승인된 한지 셰이더 원문 보존 확인. 약215m 실제 산책과 네 전각 참배 통과. PC·터치 클릭 보행, 평평한 흙길·돌길/중앙 마당/물 마스크 제외, 낮 후광/바닥 빛 비활성, 밤5색 배치/472개(440+장식32) 후광·바닥 빛 활성, 기존 소유자 LED 강도 유지 확인. 추가 실제 광원0개.

주변 흙도 따뜻한 중간 톤으로 맞추되 돌길·중앙 마당은 기존 재질을 유지한다. 증거는 evidence/soil-lantern/. 재현 스크립트는 독립 체험판의 scripts/check-soil-lantern.mjs, check-soil-lantern-views.mjs, check-woodland-walk.mjs다.
