- M4 / Epic #1 / #64: PC/터치 모의에서 탐방→가이드와 수행→종·쉼터·소원 동전·스님 인사→개인 공간 전시·수행·풍경·귀환→재입장을 검수한다. 다섯 아이템은 공개 조회·자리 선택까지만, 예약·결제 쓰기를 발생시키지 않는다. 다섯 고민 코스와 자동 108배의 시작·중단·재개를 기존 검수와 연결한다. 예상 S.

## 준비 중 발견 사항

기존 Mac Colyseus 서버가 종료 상태였고, 공개 v48의 임시 통로 주소는 이전 값이었다. 기존 서버 실행 방식으로 복구하고 현재 임시 주소로만 갱신했다. AWS·새 계정·가격/결제 변경은 없다. 공개 후보 v49를 기준으로 검수를 시작한다. 임시 Mac 서버는 계속 켜져 있어야 한다는 기존 제약을 유지한다.

증빙: evidence/web-review-v48 (폴더 이름은 기능 기준 버전을 나타내며 실제 공개 측정 버전은 각 JSON에 기록).

## #66 관찰과 보완

- v49의 첫 본 측정에서 재방문 5.676초로 5초 기준 초과. 통과로 표시하지 않았다.
- CPU 표본에서 반복 전각 Mesh.clone의 전체 객체/프로토타입 복사 비용이 컸다. 정적·단일 재질·비계층 건축물에 한해 기존 정점 버퍼를 공유하고 필요한 변환·재질·선택/그림자 속성을 복사한다. 애니메이션·자식·스켈레톤·다중 재질 등은 기존 clone 경로를 보존한다.
- 공개 v49와 개선 후보의 모든 합쳐진 건축물 정점·법선·면 인덱스·재질·정점 수가 정확히 같음을 브라우저에서 대조했다. 품질·밀도를 낮춘 최적화가 아니다. v50에 반영했다.
- v50 첫 장시간 회차는 과거 2.2 m/s에서 사용한 0.41초 옆걸음이 현재 3.4 m/s에서는 안내 스님 위치와 겹쳤다. 실제 이동거리 185m·왕복 1회로 미달해 해당 회차를 무효로 분리했다. 스님 위치나 충돌을 변경하지 않고 검사 경로의 옆걸음만 0.17초로 조정한다.
- 이전 실패·도구 진단 자료는 performance-before, performance-blocked-route 및 loading-profile에 보존하고 최종 통과 자료와 분리한다.

## #66 최종 측정 결과

공개 v50, 동일 에셋 지문 유지. Apple M5 Pro / Chrome / 1280×720 / PC 고품질 / 연등 440개 / 초기 가상 방문객 19명. 20 Mbps·80 ms에서 첫 방문 7.421초·재방문 4.081초로 기존 15초·5초 기준 통과.

120초 예열 후 각 300초 실제 보행: 낮 평균 60.00 FPS·하위 1% 54.29, 해질녘 60.00·55.67, 밤 60.00·54.53. 각 약 1,020m·10회 방향 전환으로 경로 검증도 통과. 개인 공간 10회 출입의 GC 후 JS 힙 증가 2,628,200바이트(약 2.51 MiB). GPU·전체 프로세스 메모리 또는 실기기 결과가 아니다.

추가한 개인 풍경은 각 30초의 실제 시점 변화로 별도 측정했다. 도시/한강/단풍/설경 평균은 각각 약 60 FPS, 하위 1%는 55.77/56.15/53.75/51.32 FPS다. 이 짧은 풍경 검사는 5분 보행 본 측정과 구분한다. 화면 예외·공개 API의 실제 네트워크 요청은 0건. 운영 부하·실사용자 평가와 구분한다.

## #77에서 관찰한 실제 UI 결함

- 새 NPC 대화는 장면 사전 준비 중 만들어지므로, 언어를 고른 뒤 본문은 갱신돼도 초기 생성된 닫기 버튼은 한국어로 남았다. locale-ready 이벤트에서 해당 버튼도 갱신하고 장면 종료 시 이벤트를 제거한다.
- 포르투갈어 절하기 문구가 작은 세로 화면의 격자 칸을 넘었다. 수행 영역 ID 선택자의 nowrap 규칙이 일반 모바일 줄바꿈보다 강하게 적용된 것이 원인이었다. 개인 공간 하단 조작에 한정해 줄바꿈 우선순위를 수정했다.
- 짧은 가로 터치 화면은 좌측 이동 조작과 하단 버튼이 겹치지 않도록 오른쪽 5칸 격자로 정리하고, 수행 중에는 기존 진행창을 침범하지 않는 별도 너비를 사용한다. 기존 버튼·기능은 유지한다.
- interfaces-before, interfaces-wrapping-before는 실패를 확인한 당시 자료이며 최종 통과로 해석하지 않는다. 검수 도구의 진단 출력 변수 오류는 제품 오류와 구분해 바로잡았다.

## #77 최종 결과

14개 언어 모두 새 안내창·직원 대화·개인 풍경·명시적 1/3인칭 조작을 320×740 세로와 740×320 터치 가로 화면에서 통과했다. 실제 버튼 경계·가림·가로 넘침과 한국어 폴백을 확인했다. 같은 14개 언어에서 자동 108배 일시정지·키보드 계속하기·종료, 고민 안내·도착 지도, 개인 명상·기립 종료 및 새로고침 언어 복구도 통과했다. 브라우저 터치 모의 결과이며 실휴대폰·원어민 감수 결과가 아니다.

## #64 통합 동선 1차 결과

PC 1440×900 및 터치 390×844에서 자유 탐방·바닥 탭 이동, 비회원 다섯 아이템 자리 선택, 종치기, 차/커피 마시기·기립, 소원 동전 3초 카운트, 비질 스님 말풍선·음성, 자동 108배 로그인 연결·중단, 개인 공간 전시 저장·명상 종료·참배 완료·귀환·재입장 유지, 일정 네 개·야간 화면을 통과했다. 예약·결제 관련 쓰기 요청은 없었다. 추가로 다섯 고민 코스와 자동 108배 경계 검수를 이어간다.

## #64 최종 결과

다섯 고민 코스의 PC·터치 총 10개 실제 참배·무료 완료, 코스 변경·자유 탐방 복귀를 통과했다. 자동 108배는 실제 두 번 이상 반복, 한 절 마친 뒤 일시정지, 시간·횟수 정지, 재개, 중단 후 반복 없음과 사용자 시점 유지 확인. 완료 경계는 107회 시작 시험 응답에서 한 번만 108회를 기록하고 109회를 실행하지 않음을 확인했으며 실제 108회 전체를 기다린 내구 시험은 아니다.

원본 120개·체험판 59개 단위 검사와 양쪽 타입·빌드 통과. 로컬 새 UI, 기존 다국어 수행, PC/터치 전체 동선의 최종 결과는 모두 통과다. 다국어 UI 수정 후에는 공개 게시본을 다시 짧게 검수한다. 성능 본 측정은 건축물 공유 개선을 포함한 v50이며, 이후 변경은 닫기 버튼 언어 갱신과 반응형 하단 UI에 한정한다.

## 최종 체험판 반영

UI 보완을 공개 v51(88ab0f3c9f20840d7908c7b430df5a7664f80f3d)에 게시했다. 공개 주소에서 일본어·포르투갈어·프랑스어 대화·풍경·시점 버튼의 세로/가로 배치를 다시 통과했다. 최종 게시본의 20 Mbps/80 ms 로딩 재검사는 첫 방문 7.377초·재방문 4.161초로 통과했다. 긴 보행 성능 수치는 v50, 이후 UI만 보완한 v51에서는 공개 로딩·해당 UI를 다시 확인한 결과이며 같은 버전의 15분 보행을 반복했다고 표시하지 않는다.

M4 기존 #66·#77·#64의 승인된 후속 검수 완료. 가격·결제 변경 없음, 다섯 실제 참가자 평가·실휴대폰·운영 다인 부하는 계속 제외. GitHub Issue 상태/정책 승인 변경은 수행하지 않았다. 게시·검수 영수증은 evidence/web-review-v48/publication.json과 summary.json이다.
