## 구성

- 도심: 높이·재질·옥상 형태가 다른 실제 건물, 입체 창문, 도로·조명·차량 불빛, 층을 줄여 올린 중심 고층 건물. 사진·건물 파노라마 텍스처 없음.
- 한강뷰: 양쪽 강변 건물·공원·도로, 세 개의 실제 교량(사장교 포함), 넓은 3D 수면, 노을 하늘과 햇빛 반사. 수면 물결은 위치·시간에 따라 계산하며 효과 완화 시 움직임을 줄인다. 개별 건물의 정밀 거울 반사나 실제 서울 지형 복제로 표시하지 않는다.
- 밤바다: 넓은 수면, 달빛·잔물결, 해안 바위와 먼 배의 불빛. 물의 끝은 가시 범위 밖에 두고 먼 거리 안개와 하늘로 연결.
- 단풍 산: 같은 지형의 능선·바위 봉우리와 다채로운 입체 단풍 잎·가지·숲 군락. 가까운 나무와 먼 숲을 구분.
- 설경: 같은 지형에 눈 덮인 비탈·바위, 눈을 얹은 침엽수와 낙엽수 가지. 실제 달과 관계없이 개인이 선택.
- 아래 시점: 도시·강에서는 건물 외벽과 지상 구조, 바다·산에서는 해안 또는 지형이 보이며 큰 갈색 임시 면을 사용하지 않음.

## 리소스 및 호환

선택한 풍경만 생성한다. 반복 건물·창문·잎·가지·다리 부품은 재질별 thin instance로 묶고, 창문마다 개별 광원은 만들지 않는다. 모바일에서는 먼 창문과 숲의 반복 수를 줄인다. 전환 시 메시·재질·야경 효과를 해제하고, 비활성 장면에서는 기존 렌더 중단 동작을 따른다.

저장 키 sasa:private-scenery:v1과 기존 mountain 식별자를 보존해 이전 산뷰 선택은 단풍 산으로 이어진다. 새 snow 선택을 추가했다. 기존 개인 방·전시·로그인·수행·접수·모금 데이터는 변경하지 않는다.

검수 중 기존 Mac 임시 통로가 새 주소로 갱신된 것을 확인했다. 같은 Mac 서버의 새 주소를 클라이언트에 맞췄으며 새 서버나 공개 운영 환경을 만들지 않았다. 기존 임시 주소 수명과 Mac 실행 조건을 그대로 따른다.
