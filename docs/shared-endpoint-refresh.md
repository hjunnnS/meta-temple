# 공유 서버 주소 갱신과 3개 브라우저 재검수

2026-11-20 사용자 승인 작업. 기존 M3 / Epic #3 / Implementation #54(채널·재접속)와 M4 / Epic #3 / #68(동시 접속 검수)의 후속 범위다. 새 Issue를 중복 생성하거나 기존 승인 상태를 덮어쓰지 않는다. 예상 구현 S·검수 S, 브라우저·게시 대기는 별도이며 목표 날짜는 추가하지 않는다.

## 변경과 완료 조건

공개 v52와 로컬 기본 설정에 남은 `untitled-january-productivity-suggestions.trycloudflare.com`을 현재 Mac 공유 서버의 `romance-vinyl-challenged-wash.trycloudflare.com`으로 갱신한다. 두 소스의 기본값과 원본의 로컬 service 빌드 설정을 일치시키고, 빌드 산출물에서 이전 주소가 남지 않음을 확인한다. 현재 주소의 health와 체험판 Origin 허용을 확인한다.

3개 독립 Chrome 프로세스가 실제 외부 Colyseus 서버의 채널 3에 동시 접속해 각자 다른 두 명의 캐릭터, 정확한 접속자 표시, 이동·외형·참배 동기화, 개인 공간 격리·귀환, 오프라인·새로고침 복구를 통과해야 한다. 로컬 검수 후 기존 공개 체험판에 게시하고 공개 주소에서도 반복한다. 실제 사람 3명의 참여 평가 또는 서로 다른 물리 기기 3대 검수로 표시하지 않는다.

그래픽·수행·계정·가격·결제는 변경하지 않는다. Mac 서버를 재시작하지 않고 정적 체험 파일도 최신 빌드로 동기화한다. 기존 파일을 먼저 복사하고 index를 마지막에 교체해 현재 사용 중인 파일을 지우지 않는다.

## 사전·로컬 결과

- 현재 서버 `/healthz` HTTP 200, Colyseus 0.16/WebSocket, layout-web-015, 채널 3개·채널당 20명. 공개 체험판 Origin이 허용된 응답도 확인했다.
- 양쪽 타입·빌드 통과. 체험판 빌드에 현재 주소만 포함됨을 확인했다. 환경 설정이 이전 주소로 기본값을 덮어쓰는 경우도 함께 갱신했다.
- 독립 브라우저 3개, 고유 세션 3개, 각자 원격 캐릭터 2개와 ‘3명 접속 중’ 확인. 실방문 세션 3개에서 가상 방문객 목표 17명을 확인했다.
- 세 방향의 실제 이동 전달, 토끼 외형·법복 전달, 참배 동작 전달, 개인 공간 진입 시 다른 화면에서 제외 및 귀환 후 중복 없는 재참여를 통과했다.
- 한 브라우저의 오프라인 전환·복구, 창 닫기와 새로고침 후 인원 수렴을 통과했다. 실제 WebSocket 연결 호스트는 현재 주소였고 페이지 예외·구형 presence 요청 실패는 없었다.
- 브라우저 기본 favicon 404와 의도적으로 오프라인으로 만든 브라우저의 네트워크 오류는 제품 실패와 구분한다. 공개 후 검사에서는 favicon을 제외한 HTTP 오류도 별도 수집한다.

로컬 증빙: evidence/shared-endpoint-refresh/local/result.json 및 녹화/스크린샷. 공개 게시 영수증과 후속 결과는 같은 폴더의 publication.json, published/result.json으로 구분한다.

## 운영 한계

이번 작업은 기존 Mac 임시 공유 방식의 복구다. Mac 서버가 계속 실행돼 있어야 하며, 임시 터널 주소가 다시 바뀌면 공개 체험판 주소도 다시 맞춰야 한다. 고정 주소·상시 호스팅 전환은 이번 범위가 아니다.


## 공개 v53 최종 결과

체험판 v53, 소스 4908cce3d67c395a742d7a22a368635a6fb6b027, 배포 성공. 기존 공개 주소와 공개 범위를 유지했다.

공개 주소에서 별도 Chrome 프로세스 3개의 고유 세션이 동시에 채널 3에 연결됐다. 각 화면의 원격 캐릭터 2개, ‘3명 접속 중’ 표시, 실방문 세션에 따른 가상 방문객 17명 조절을 확인했다. 이동·토끼 외형·법복·참배 동기화, 개인 공간 격리·귀환, 브라우저 오프라인 제거와 자동 재접속, 창 닫기·새로고침 후 인원 수렴이 모두 통과했다.

실제 WebSocket 호스트는 romance-vinyl-challenged-wash.trycloudflare.com이었다. 페이지 예외, 구형 presence 요청 실패 및 favicon을 제외한 HTTP 오류는 모두 0건이다. Mac 서버는 종료하거나 재시작하지 않고 계속 실행 상태로 남겼다. 공개 후 3개 브라우저는 검수 종료 시 정리했다. 기존에 열려 있던 v52 창에는 새 주소가 자동 적용되지 않으므로 새로고침이 필요하다.

v52 모바일 재검수에서 발견한 공유 서버 주소 불일치는 이번 승인된 후속으로 해결됐다. 3개 독립 브라우저 검수이며 실제 사람·물리 기기 3대 검수로 표시하지 않는다. 검수 결과는 published/result.json, 화면은 published/three-online.jpg와 three-visitors.jpg, 게시 영수증은 publication.json이다.
