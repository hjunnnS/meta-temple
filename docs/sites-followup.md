- M1 / E04 #4 / #12: Playwright 1.62.1을 잠금 파일에 고정하고 개인 Mac의 모듈 경로를 제거했다. 로컬 서버 시작·종료를 검사 스크립트가 관리한다. GitHub `trial/sites-personal` 전용 Actions를 구성했다. 추적되어 있던 개발 PC의 node_modules 링크를 제거하고 각 환경에서 독립 설치한다. 빈 디렉터리에서 `npm ci`, 테스트·타입·빌드를 통과했다. CI 실행 결과는 별도로 기록한다.
- M4 / E01 #1 / #64: 실제 클릭·터치 보행, 종/당목·종소리, 차와 커피 마시기·일어나기, 동전 3→2→1과 연출 종료, 비질 스님 인사·말풍선·음성, 탑·대불·산책·참배 복귀를 검증한다. 종치기 중 쉼터 이동에서 이전 동작이 남는 결함을 수정했다. 음성 검사는 브라우저의 실제 버퍼 소스 재생 시작과 음원 해독을 기록하며 주관적인 음질 감수는 아니다.
- M4 / E04 #4 / #66: 실제 Sites HTTPS 주소의 20 Mbps·80 ms 첫 방문/재방문, 1280×720 고품질·연등 440개, 2분 예열 후 낮/해질녘/밤 각 5분 보행과 개인 공간 10회 출입을 자동화했다. 장시간 본 측정은 업데이트 배포 후 실행한다. 10초 smoke 모드는 검사 도구 확인용이며 합격 측정을 대신하지 않는다. 플랫폼이 요청마다 넣는 HTML 내용 대신 Vite 산출물 경로와 고정 에셋 명세로 동일 배포 여부를 확인한다. JS 힙은 GC 후 비교이며 GPU/전체 프로세스 메모리와 구분한다. 기존 15초/5초 로딩 기준 외 FPS 값은 실제 측정 결과로 보고한다.
- M4 / E05 #74 / #76: 체험 안내·브라우저 저장·메모리 모드·체험 시작/나가기/초기화·저장 실패·아이템 수 16종을 한국어 및 13개 번역 카탈로그에 연결했다. 언어 선택 전에 생성된 체험 안내도 입장 시 갱신한다. 샘플/신청자가 작성한 이름·문구는 저장 원문을 유지한다.
- M4 / E05 #74 / #77: 14개 언어에서 실제 다섯 신청, 게스트의 같은 자리 복귀, 개인 공간 배치·새로고침 복원, 선택 언어 유지, 뒤로 가기와 Escape 초점 복귀를 확인했다. 외국어는 320×740 터치 화면이다. 저장 차단 메모리 모드와 실패 안내도 영어 화면에서 실행했다. 재방문 때 닫았던 체험 안내가 다시 펼쳐져 입구를 가리는 결함을 수정해 같은 탭에서 닫은 상태를 유지한다. 원어민·종교 감수 및 실휴대폰 성능 합격을 뜻하지 않는다.

전용 자동 검사 4개(브라우저 간 상태 분리·거래/전시 정합성·예약/수행·번역 키 및 자리표시자), 타입·빌드, 기본 동선, PC/터치 확장 동선, 14개 언어 기능 검수가 통과했다. 화면 오류·실패 에셋·Mac API 네트워크 요청은 0건이다. 통합 요약은 `evidence/sites-followup/functional-summary.json`, 실행 로그·화면은 같은 폴더의 각 검사 기록을 참조한다.

체험판의 공개 범위와 개인정보 입력 없는 로컬 저장 방식은 유지한다. 실제 로그인·결제·여러 방문자 동기화와 #71 정식 출시 판정은 포함하지 않는다.

GitHub 기본 headless shell에서 클릭 준비가 지연된 실패 화면을 확인한 뒤, Playwright가 지원하는 실제 Chromium의 새 headless 모드와 Linux 검수용 소프트웨어 렌더러를 명시했다. 화면 품질·슬롯 수·기능 검증 조건은 낮추지 않는다. 실제 FPS 판정은 별도 Mac GPU 측정으로 보고한다.

장시간 측정의 첫 시도는 설정 창 닫힘 후 초점 복귀가 늦어 실제 보행 경로를 충족하지 못해 무효 처리했다. 측정 스크립트에서 닫힘 이벤트 완료와 캔버스 초점을 확인하도록 보완했으며 실제 이동 범위·회전 수 조건을 유지한다. 정지 화면의 FPS를 보행 합격으로 사용하지 않는다.

CI 범위 확정: GitHub 일반 CPU 실행기는 전체 고품질 WebGL 동선에서 108배 1회가 고정 대기 시간 안에 끝나지 않았다. 그래픽을 낮추거나 완료 판정을 우회하지 않고, 자동 필수 검사를 상태/번역 단위 검사·타입·빌드·정적 에셋 해시/호스팅 명세로 구분했다. 전체 실제 브라우저 검사는 재현 명령을 유지하고 수동 workflow 옵션으로도 제공한다. 이번 통과 근거는 Mac의 전체 실제 동선·14개 언어와 공개 주소의 PC/터치 검사이며 CPU 실행기 전체 WebGL 통과라고 기록하지 않는다. 문서·증빙만 바뀔 때는 동일 실행을 불필요하게 반복하지 않도록 Actions 경로 조건을 추가했다.
