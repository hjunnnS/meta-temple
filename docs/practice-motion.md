## 변경
- 왼쪽 위 작은 상태 카드: 녹색 표시 + 수행 종류, mm:ss 경과 시간. 108배는 큰 `완료 횟수 / 108` 및 진행 막대. 색에만 의존하지 않으며 시간의 매초 화면 읽기는 끈다. 모바일에도 고정한다.
- 횟수는 완료 응답의 count만 사용하며 애니메이션 도중 선반영하지 않는다. 같은 기존 `bow-count` 계약은 보존하고 표시만 통합한다. 이 문서 작성 당시 108배는 수동 방식이었으며, 최종본은 auto-bows.md의 연속 진행·일시정지·계속하기 방식이 우선한다.
- 일반·108배·개인 절하기를 6.8초의 공통 길이로 맞췄다. 기존 접촉 자세는 보존하고 시간 곡선으로 합장 준비·체중 지탱·바닥 머무름·기립을 분리한다. 원격 표시에도 같은 길이를 사용한다.
- 의자에 즉시 위치·자세를 적용하던 동작을 접근→방향 맞추기→약 1.35초 착석→휴식/음료→약 1.15초 기립으로 연결한다. 착석 도중 취소도 현재 앉은 정도에서 일어난다. 멀리서 지도 이동으로 쉼터를 선택하는 기존 장소 전환은 유지하며 근처 의자는 실제 보행 경로를 사용한다.
- 등받이를 통과하지 않고 앞에서 앉도록 테이블은 그대로 두고 의자를 0.65m 뒤로 옮겨 접근 공간을 확보했다. 테라스·실내·야외 의자 모델·재질과 사찰/판매 아이템 배치는 유지한다.
- 걷기는 시작·정지를 부드럽게 연결하고 최단 방향으로 회전한다. 팔과 다리를 반대로 흔들고 발목/골반으로 지지 발을 맞춘다. 공용 공간 속도 2.2m/s, 개인 공간 2.1m/s로 보폭에 맞춰 조정했다. 카메라나 보행 바닥을 위아래로 흔들지 않는다. 가상 방문객·산책 스님도 같은 보행 자세를 사용한다.
- 새 상태 문구 5개는 기존 14개 언어에 맞췄다. 새 영구 데이터나 서버 정책은 추가하지 않았다.
