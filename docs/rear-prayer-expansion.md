## Implementation Issue 작업 구분

아래는 로컬 구현 단위이며 GitHub 신규 Issue를 등록한 것이 아니다. 작업량은 구현 단위에만 기록하며 총계에 중복 산입하지 않는다. 예상 작업량은 상대 규모로 구분한다(소/중/대). 예비 시간과 승인 대기 시간은 포함하지 않는다.

1. **지형·담장·순환 산책길**
   - 예상 작업량: 중.
   - 범위: 승인 좌표로 뒤편 경계 확장, 내부 기존 담 제거, 산 배경의 평지 범위 보정, 보행·클릭 이동·방문자 좌표 범위 확장.
   - 선행: 사용자 배치 승인(충족).
   - 완료 조건: 기존 마당은 그대로이고 확장 구역과 새 길을 이용할 수 있다.
   - 검증: 경계·길·벽 여유 단위 검사와 실제 브라우저 보행.
2. **네 전각과 불·보살**
   - 예상 작업량: 대.
   - 범위: 기존 건축 템플릿의 기와·단청·목재 유지, 각 불단·금빛 좌상·촛불·방석·열린 입구. 기존 조형 얼굴·법복 주름 재사용.
   - 선행: 1.
   - 완료 조건: 약사전은 동쪽 입구/약사여래불, 문수전은 남쪽/문수보살, 보현전은 남쪽/보현보살, 극락전은 서쪽/아미타불. 입구 반대편 안쪽에 불단 배치.
   - 검증: 네 전각 실제 화면, 계단 출입·참배·실내 줌 검수.
3. **지도·다국어·회귀 검수와 결과 이미지**
   - 예상 작업량: 중.
   - 범위: 기존 지도 번호 보존하며 네 장소 추가, 새 검수 시점 추가, 다국어 명칭과 위치 동기화, 전체 배치와 산책길 증거 이미지.
   - 선행: 1·2.
   - 완료 조건: 기존 531자리의 ID·좌표·방향·종류가 그대로이고 빌드·단위·브라우저 검사를 통과한다.

## Sites 체험판 반영

공개 체험판에도 같은 지형·건축·불단·보행·지도·다국어 명칭을 반영한다. 기존 브라우저 저장, 시험 신청, 개인 공간, 실제 과금 없음, 외부 API 비의존 범위는 유지한다. 체험판 검수와 배포 결과는 체험판의 evidence/rear-prayer-expansion/에 별도로 기록한다.

## 체험판 배포 전 검수

독립 체험판 14개 단위 검사, 타입·정적 빌드·19개 정적 에셋 기록 검사 통과. 새 네 전각의 실제 계단 퇴장·클릭 재입장·참배와 카메라 96개 경우, 낮·야간을 확인했다. 기존 다섯 아이템의 게스트 신청 복귀·시험 설치, 108배, 개인 공간 전시와 새로고침 저장, 일정·야간과 390px 터치 검수도 통과했다. 외부 API 네트워크 요청·화면 오류·실패 에셋은 모두 0건이다. 기존 531개 자리 전체 데이터가 원본과 동일하다. 확장된 맵으로 입장 배경도 갱신했다.

사용자 승인에 따라 같은 공개 주소와 접근 범위를 유지하여 배포한다. 실제 과금·Firebase·서버 다중 사용자 기능을 추가하지 않는다. 배포 버전과 검수 영수증은 공개 반영 후 별도로 기록한다.
