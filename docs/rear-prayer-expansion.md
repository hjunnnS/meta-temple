# 대웅전 뒤편 확장과 네 기도 전각

사용자가 승인한 `planning/rear-expansion-deities/map.png` 및 내부 도면을 기준으로 실제 맵을 확장한다. 날짜 목표를 새로 설정하지 않는다. 이 문서는 이번 구현 범위를 기록하며 기존 GitHub Issue 번호·내용·승인 상태는 변경하지 않는다.

## Milestone · M2 공간 구성 보완

완료 조건: 기존 시설·531개 아이템 자리와 품질을 유지하면서 뒤편 확장, 네 전각·불단·방석·진입로를 구현하고 로컬에서 보행과 실내 카메라를 검수한다.

## Epic · 뒤편 기도 구역

포함: 북쪽 38m, 서쪽 뒤편 21m, 동쪽 뒤편 19m 확장. 약사전·문수전·보현전·극락전, 각 불·보살, 순환 산책길, 담장 이설, 지도와 이동·참배 연결.

제외: 새로운 유료 자리·기간·가격 정책, 브랜드 변경, 고민별 가이드, 종교 감수 승인, 공개 배포, 커밋·푸시.

## Implementation Issue 작업 구분

아래는 로컬 구현 단위이며 GitHub 신규 Issue를 등록한 것이 아니다. 작업량은 구현 단위에만 기록하며 총계에 중복 산입하지 않는다. 예상 작업량은 상대 규모로 구분한다(소/중/대). 예비 시간과 승인 대기 시간은 포함하지 않는다.

1. **지형·담장·순환 산책길**
   - 예상 작업량: 중.
   - 범위: 승인 좌표로 뒤편 경계 확장, 내부 기존 담 제거, 산 배경의 평지 범위 보정, 보행·클릭 이동·방문자 좌표 범위 확장.
   - 선행: 사용자 배치 승인(충족).
   - 완료 조건: 기존 마당은 그대로이고 확장 구역과 새 길을 이용할 수 있다.
   - 검증: 경계·길·벽 여유 단위 검사와 실제 브라우저 보행.
2. **네 전각과 불·보살**
   - 예상 작업량: 대.
   - 범위: 기존 건축 템플릿의 기와·단청·목재 유지, 각 불단·금빛 좌상·촛불·방석·열린 입구. 기존 조형 얼굴·법복 주름 재사용.
   - 선행: 1.
   - 완료 조건: 약사전은 동쪽 입구/약사여래불, 문수전은 남쪽/문수보살, 보현전은 남쪽/보현보살, 극락전은 서쪽/아미타불. 입구 반대편 안쪽에 불단 배치.
   - 검증: 네 전각 실제 화면, 계단 출입·참배·실내 줌 검수.
3. **지도·다국어·회귀 검수와 결과 이미지**
   - 예상 작업량: 중.
   - 범위: 기존 지도 번호 보존하며 네 장소 추가, 새 검수 시점 추가, 다국어 명칭과 위치 동기화, 전체 배치와 산책길 증거 이미지.
   - 선행: 1·2.
   - 완료 조건: 기존 531자리의 ID·좌표·방향·종류가 그대로이고 빌드·단위·브라우저 검사를 통과한다.
   - 검증: `tests/rear-prayer-halls.test.ts`, `scripts/check-rear-prayer-expansion.mjs`, 기존 검사.

## 실제 배치

- 약사전 (-44,55), 동쪽 입구, 서쪽 안쪽 불단.
- 문수전 (-22,99), 남쪽 입구, 북쪽 안쪽 불단.
- 보현전 (40,102), 남쪽 입구, 북쪽 안쪽 불단.
- 극락전 (82,69), 서쪽 입구, 동쪽 안쪽 불단.
- 모든 건축물은 기준 지붕 약 14×12m. 동서로 돌린 전각은 그 치수가 회전한다.
- 대웅전·관음전·지장전·야외 미륵보살 석상과 기존 아이템 배치는 유지한다.
- 수인·장식의 종교적 최종 감수와 그래픽 품질에 대한 사용자 승인은 별도이다.

## 로컬 검수 결과

- 단위 검사 78개와 TypeScript·서비스 빌드, 기존 19개 에셋 출처·해시 검사 통과.
- 기존 531개 슬롯 전체 기록(ID·좌표·방향·종류)을 수정 전과 비교해 동일함을 확인.
- 네 전각 모두 지도 이동 → 실제 계단으로 퇴장 → 마우스 클릭으로 계단 재입장 → 참배 확인.
- 새 전각의 카메라 회전·줌 96개 경우에서 지붕 아래 제한을 확인. 기존 대웅전 회전·천장·현판·출입 120개 검사도 통과.
- PC와 320px 터치 화면에서 기존 18개와 새 4개를 합친 22개 지도 장소의 선택·이동·포커스 확인.
- 낮과 야간 실내·산책길 화면을 확인. 정식 실기기 성능 승인으로 간주하지 않음.
- 이번 작업은 이 Mac의 로컬 구현·검수이며 GitHub 등록·커밋·푸시 또는 공개 배포를 수행하지 않음.

## GitHub 보관·체험판 반영 승인

사용자가 후속 요청으로 이 구현과 검수 결과의 커밋·푸시 및 기존 공개 체험판 반영을 승인했다. 원본은 기존 `m4/web-acceptance`, 독립 체험판은 `trial/sites-personal`에 보관하고 기존 이슈·Milestone의 번호와 상태는 유지한다. 기존 승인된 조경·카메라·지도 보완 중 이번 확장의 기반이 되는 소스도 함께 보관한다. 배포 완료 여부와 버전은 후속 배포 기록으로 확인한다.
