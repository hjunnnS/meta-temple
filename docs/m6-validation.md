# M6 수행 경험·안내 흐름·야간 환경 개선

2026-11-13 사용자 승인에 따라 Milestone M6와 구현 Issue #87~94를 등록하고 순서대로 구현했다. 기존 Epic #1에 7개, Epic #2에 상품 관련 #91을 실제 하위 관계로 연결했다. 예상 작업량은 구현 Issue에만 기록하고 목표 날짜는 설정하지 않았다.

## 구현 결과
- #87: 참배 시 기도문만 낭독하는 한국어 음성, 임시 목탁·명상 자연음, 합장/무릎/절/일어남 단계 표시, 호흡 안내와 짧은 완료 빛. 108배의 기존 완료 효과와 로그인·기록 규칙은 유지한다. 명상 빛은 낮은 강도로 적용했다. 개인 공간의 절·명상에도 같은 피드백을 적용했다. 취소·음소거·탭 숨김 시 소리를 정리하고 탭 전환으로 기존 절 횟수를 잃지 않도록 했다.
- #88: 고민별 전각을 찾는 이유·모신 불보살 소개를 기존 안내에 포함했다. 가이드 중 일반 수행 진입을 숨기거나 잠그고 가이드 내부에서 수행한다. 수행 후 바로 무료 완료하며, 연등·소원패·산책 등은 종료 후 자유 선택으로 설명한다. 자동 판매 장소 이동을 없앴다.
- #89: 문수전과 같은 템플릿을 쓰는 전각의 입구 중앙 기둥·받침·장식을 제거했다. 양옆 구조와 건물 재질은 유지하며 실제 보행·카메라 충돌에도 제거 상태를 반영했다.
- #90: 아이템 전시 확인 후 배치 마치기를 누르면 원래 아바타 위치와 3인칭 시점으로 약 0.65초 동안 부드럽게 돌아온다. 저장·재입장과 기존 벽 가림 방지는 유지한다.
- #91: 연등 배치도에 선택 가능·예약 중·설치됨·선택 상태와 위치 요약을 표시하고 선택이 무효화되면 안내도 갱신한다. 다섯 아이템의 시험 기간은 7·21·49일이다. 새 시험 가격은 각각 3,000·9,000·21,000원이며 실제 판매가격 확정이 아니다. 기존 30일 주문·예약·설치의 기간과 금액은 보존한다. PostgreSQL은 신규 마이그레이션 014로 이전 시험 판매 옵션만 비활성화한다.
- #92: 건물 외벽과 출입 바닥의 따뜻한 빛, 주요 담장에 간격을 둔 조명 표현, 석상 조명 보강과 연등 아래 색 번짐을 추가했다. 입구 통로에 빛의 막이 생기지 않게 외벽 위주로 제한했다. 야간 전용 공통 조명 2개와 공유 텍스처를 사용하며 연등마다 동적 광원을 만들지 않는다.
- #93: 개인 공간의 귀환 문에도 보라·파랑·주황 연무를 재사용한다. 가까이에서 귀환 버튼을 표시하며 걸어서 나가기·기존 귀환 버튼을 유지한다. 반복 출입 시 개인 장면·효과·입력·음원을 해제한다.
- #94: 비질 스님 곁 통행을 방해하지 않는 위치에 쉬는 작은 강아지 한 마리를 배치했다. 호흡·미세 고개 동작만 제공하며 먼 거리·효과 완화에서는 동작을 줄인다. 추적·짖기·보상 기능은 없다.
