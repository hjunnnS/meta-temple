# 지도 불·보살·기도 주제 안내

## 관리와 범위
- M5 / Epic #1 / Implementation #86.
- 사용자가 지도 안내 Issue 검토 후 2026-11-13 구현 승인.
- 여섯 전각의 기존 지도 목록에 짧은 대표 주제 추가. 선택 시 전각·불보살 이름, 대표 기도 주제, 한 문장 설명과 기존 이동 버튼 제공.
- 기존 건물·아이템·좌표·스님 가이드 유지. 새 메뉴·팝업·입구 안내판·새 가이드 코스 없음.
- 기존 14개 언어에 적용. 번역 추가는 독립 체험판 고유 문구를 보존하며 병합.

## 안내 문구
- 관음전 / 관세음보살 / 가족과 평안: 나와 가족의 평안과 어려운 마음의 위로를 기원하는 곳입니다.
- 약사전 / 약사여래불 / 건강과 회복: 나와 가족의 건강, 회복과 쾌유를 기원하는 곳입니다.
- 지장전 / 지장보살 / 추모와 위로: 떠난 이의 평안과 남겨진 이의 위로를 기원하는 곳입니다.
- 문수전 / 문수보살 / 배움과 지혜: 배움과 시험을 앞두고 지혜와 마음의 안정을 기원하는 곳입니다.
- 보현전 / 보현보살 / 관계와 실천: 관계 속에서 배려와 바른 실천을 다짐하는 곳입니다.
- 극락전 / 아미타불 / 극락왕생: 극락왕생과 떠난 이의 평안을 기원하는 곳입니다.

모두 대표적인 기도 주제이며 다른 기도를 제한하거나 효험·건강 회복·시험 결과를 보장하지 않는다. 가족·시험·관계 등의 설명은 기존 사용자 승인 시험 코스를 쉽게 안내하는 서비스 문구다. 정식 종교·원어민 감수는 기존 후속 대기다.
