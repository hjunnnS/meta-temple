## 로컬 검수 완료

- 원본 자동 검사 74개, 체험판 자동 검사 10개와 타입·빌드·19개 에셋 출처/해시 검증 통과.
- 지도 18개 번호 모두 PC 클릭·320px 터치·Enter·Space, 목록 선택과 강조 일치, 확인 후 이동·초점 복귀 통과. 현재 위치 표식도 번호 입력을 가리지 않는다.
- 실제 비회원 2명이 새 배치의 10개 목적지에서 상대 아바타를 확인했다. 참배·채널 분리·20초 단절 후 재접속·중복 아바타 없음. PostgreSQL 531자리의 ID·좌표·배치 버전 일치. 추모등 공개 철회는 2.019초, 만료는 1.923초에 두 채널에 반영됐다. 검사에서 만든 DB 계정·설치·주문·예약은 정리했다.
- 연등·소원패·인등·추모등·봉헌초 모두 비회원 자리 선택→예약에서 로그인→선택 유지→예약·취소를 실제 로컬 API로 확인했다. 시험 우편함만 사용했으며 실제 외부 메일·과금은 없다.
- 체험판 PC·터치의 다섯 신청·시험 결제·저장·재방문, 참배·개인 공간 전시·일정·종치기/소리·차/커피·동전 카운트·스님 인사·산책 복귀를 확인했다.
- 20Mbps·80ms에서 첫 3D 프레임은 최초 7.166초·재방문 2.781초로 15초·5초 기준 이내다. 입장 연출을 포함한 탐색 시작→보행 준비는 9.676초·5.297초이며 첫 프레임과 별도 지표다.

- 원본과 체험판 각각 14개 언어에서 18개 번호·목록·상세 일치, 이동·재방문 언어 유지·Escape 초점 복귀, 320px 가로 넘침 없음을 확인했다. 원어민·종교 감수나 물리 휴대폰 검수를 뜻하지 않는다.
