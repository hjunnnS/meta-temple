# 사사 Sites 개인 체험판

기준 소스: meta-temple `c724c51fdee0edb18a60a30190913ff85c9695d2`.
원본 저장소와 운영 후보를 변경하지 않고 별도 소스로 구성한다.

- Milestone: M4 웹 검수 후속. 목표는 Mac 서버 없이 1~2명이 2~3주간 공간과 조작을 체험할 수 있는 주소 제공이다. 별도 목표 날짜는 정하지 않는다.
- Epic: E04 #4의 웹 통합 검수·후보 환경. 공개 체험판은 정식 출시 #71 완료를 의미하지 않는다.
- Implementation: 기존 #70·#64 후속 범위로 Sites 호환 연결과 통합 검수를 진행한다. 새 GitHub 이슈는 생성하지 않는다. 선행은 기존 승인 UI와 사용자 Sites 공개 체험 승인이다. 예상 작업량 M, 플랫폼 배포 대기 시간은 별도다.
- 완료 조건: 언어 선택·연꽃 입장·기존 3D 공간/이펙트 유지, 개인정보 입력 없는 체험 시작, 다섯 아이템 시험 신청, 108배·개인 공간·전시 저장, 새로고침 복원, Mac API 요청 없이 실행, Sites 배포 성공 및 URL 확인.
- 제외: 실제 결제, 실제 Firebase 로그인, 서버 소유권, 다중 사용자 동기화, 운영 개인정보 및 원본 시험 DB 업로드.

## 체험 방식

공개 링크는 ChatGPT 계정 없이 접속하도록 사용자가 승인했다. 모든 체험자는 자기 브라우저의 독립 상태를 사용한다. '체험 시작'은 신원을 확인하는 로그인이 아니다. 개인 공간 샘플 다섯 개를 제공하며 실제 구매·판매 내역이 아니다. 신청 화면의 금액은 기존 시험 금액이고 어떤 과금도 발생하지 않는다.

신청·개인 공간 배치는 localStorage에 저장한다. 다른 기기나 브라우저와 동기화되지 않으며 저장소 삭제 시 사라진다. 저장소가 차단되면 메모리 모드로 안내하고 창을 닫을 때 기록이 사라진다. 민감한 개인정보는 입력하지 않는다. 로컬 시험 DB, 로그인 토큰, Firebase 키·이메일 우편함은 포함하지 않는다.

## 검증

`npm test`는 다섯 종류의 설치/중복 결제 방지, 게스트 보호, 슬롯 규격 유지, 기록 복원 및 브라우저 간 분리, 비공개 문구 가림, 전시 자리 호환/수정 충돌, 예약 만료, 108배 카운트와 초기화를 검증한다.
`npm run build`는 타입 검사와 service 모드 정적 파일을 만든다.
`scripts/check-trial.mjs`는 실제 Chrome에서 게스트 신청 후 체험 복귀, 다섯 종류 신청, 108배 동작, 개인 공간 저장·재방문, 일정·야간, 모바일 크기와 외부 서비스 API 비의존을 확인한다. 실휴대폰 성능 검수는 아니다.

Sites 소스와 배포 산출물은 Sites 저장소에 저장한다. 원본 GitHub 브랜치에 체험판 API를 합치지 않는다. 테스트 종료 후 사이트 비공개 전환 또는 배포 중지는 별도로 요청한다. 만료 자동화는 만들지 않는다.

검수 결과: 전용 자동 검사 3/3, 타입·빌드, 실제 Chrome의 다섯 신청·게스트 복귀·108배 동작·개인 공간 전시 저장과 새로고침 복원·일정/밤·390px 터치 화면 통과. 화면 오류 0건, 실패 에셋 0건, 실제 서버 API 네트워크 요청 0건. 결과와 화면은 `evidence/sites-trial/`에 보관한다. 실제 과금과 동시 접속 동기화는 시험하지 않았다.
