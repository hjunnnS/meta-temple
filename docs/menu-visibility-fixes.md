# 메뉴 시인성 네 항목 보완

2026-11-20. 사용자가 이전 메뉴 점검의 네 항목 구현·PC/모바일 검수·체험판 반영을 승인했다. 기존 M4, Epic #1·#4·#74의 Implementation #64·#77 후속이며 조이스틱 겹침은 #39 관련 범위다. 기존 Issue 번호와 승인 상태를 보존하며 중복 Issue를 만들지 않았다. 예상 작업량 S, 브라우저 및 게시 대기는 별도다. 선행 검토는 `docs/menu-visibility-v53.md`다.

## 구현 및 완료 조건

1. 공개 사찰의 접수창이 열리면 이동 조이스틱을 숨기고 이동 벡터도 초기화한다. 접수창을 닫으면 조작이 복구된다. 개인 공간의 조작에는 공개 접수창 상태를 적용하지 않는다.
2. 높이 500px 이하의 터치 가로 화면에서 접수창을 화면 높이에 맞춰 넓히고 확인 버튼을 일반 스크롤 흐름에 둔다. 기간·빈자리 선택·취소·내 예약 확인을 덮지 않는다. 가격·예약·결제 처리 코드는 변경하지 않는다.
3. 지도 번호는 SVG 크기가 줄어도 실제 14px 이상을 유지한다. 번호가 겹치면 가까운 위치로 분산하고 연결선으로 실제 장소를 표시한다. 현재 위치도 같은 방식으로 읽기 쉽게 유지한다. 모바일 지도 높이는 320px이며 기존 장소 선택과 이동 기능을 유지한다. 지도 재구성 시 크기 관찰자를 해제한다.
4. PC 연등 자리 상태 보조 글자는 10px에서 0.875rem(기본 14px)으로 확대한다.

## 검증

- 원본/체험판 빌드 성공, 단위 검사 120개/59개 통과.
- Chrome PC 1440×900, 터치 모의 390×844·320×740·740×320에서 각 35개 메뉴·상태, 총 140개 완료. 페이지 예외 0건, 스크롤 후 검사한 버튼의 가림 0건. 대량 자리 버튼은 처음·중간·끝 표본 검사이며 전수 클릭을 주장하지 않는다.
- 별도 집중 검사: 한국어 PC·320px 모바일, 독일어 390px 모바일, 러시아어 가로 화면. 번호 최소 14px, 번호끼리 겹침 및 지도 밖 넘침 없음, 실제 지도 선택 정상. 320px에서 가로 회전 후에도 재검사한다. 다섯 아이템 접수의 버튼·입력·선택을 스크롤해 실제 클릭을 받는지 검사하며 예약·결제를 실행하지 않는다. 연등 상태 글자 14px 이상 및 가로 넘침 없음, 조이스틱 숨김·복원 확인.
- 기존 체험판 v53과 건물·지형의 정점/법선/인덱스, 재질 색상·설정, 생성 텍스처 픽셀·해상도가 일치한다. 방문객 용량 20명 유지.
- 추가 조이스틱 이동·놓기·확대·개인 공간 및 PC 고품질 설정 검사를 수행한다. 원시 결과는 `evidence/menu-visibility-fixes/`에 보관한다.

실제 iPhone Safari·Android 휴대폰 및 소프트 키보드는 미검수다. Chrome 터치 모의를 실기기 검수로 표시하지 않는다. 번역 감수·가격·결제·서버 정책 변경은 범위 밖이다. 네 항목이 대상 화면에서 조작을 막지 않고 읽을 수 있으며 체험판에 동일 소스가 게시되면 완료한다.

## 게시 및 공유 연결 후속

메뉴 네 항목은 체험판 v54에 게시하고 공개 URL에서 네 화면 크기 집중 검사도 통과했다. 최종 점검 중 Mac 공유 서버가 2026-11-20 05:16 UTC에 임시 주소를 재생성한 것을 발견했다. 이전 주소는 DNS 해석 실패, 새 주소의 `/healthz`는 HTTP 200과 3채널·채널당 20명 응답을 확인했다. 기존 공유 연결 보완(#66 후속) 범위에서 현재 주소 `https://database-tip-swap-charter.trycloudflare.com`로 상수와 원본 로컬 환경 설정을 갱신한다. 서버 동작·그래픽·가격·결제는 변경하지 않는다. 갱신 게시 후 3개 독립 브라우저로 공유 연결을 재검수한다. 임시 주소는 다시 변경될 수 있으며 Mac 서버 실행이 필요하다.

최종 완료: 체험판 v55, 소스 `2c7b538e02dec26ce082f970068ca4bc4482567e`, 게시 성공. 공개 URL의 PC·320px·390px·740px 가로 집중 검사가 모두 통과했다(`published-final/result.json`). 3개 독립 Chrome 프로세스의 실 Colyseus 세션이 접속자 3명·각 2명 상대 캐릭터·가상 방문객 17명을 확인했다. 상호 이동, 12지신·승복 외형, 참배, 개인 공간 격리/복귀, 오프라인 제거/재접속, 새로고침 수렴을 통과했다(`shared-published/result.json`). 페이지 예외·검사 대상 HTTP 오류는 0건이다. 브라우저의 favicon 404와 의도적으로 끊은 오프라인 경고는 기능 오류와 구분했다. 조이스틱 회귀 검사도 공개/개인 공간과 PC 고품질을 모두 통과했다(`mobile-controls/results.json`). Mac 서버는 계속 실행 중이다.
