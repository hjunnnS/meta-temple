# 종류별 나무 군락과 빈 가장자리 조경

## Milestone · M2 공간 보완 / M4 체험 검수

사용자가 승인한 조경 방향을 기존 확장 맵에 적용한다. 목표 날짜와 새 GitHub Issue를 추가하지 않는다. 기존 건물·불단·길·담장·531개 판매 자리와 계절 표현은 유지한다.

## Epic · E01 공간 구성 (#1), E04 웹 검수 (#4)

포함: 대나무와 계절나무를 종류별 군락으로 재배치, 군락 바닥과 담장 가장자리의 낮은 풀·관목·작은 돌. 제외: 건물·판매 품목·가격·신규 기능·브랜드 변경, 기존 승인 상태 변경.

## Implementation Issue 후속

- 기존 #18·#23 / M2: 33개 대상 식재를 대나무 17무리·계절나무 16그루의 8군락으로 재배치한다. 예상 M. 선행은 뒤편 확장 승인. 완료 조건은 중앙 뒤뜰·입구·주요 길과 시야를 비우고 같은 수량으로 종별 군락이 구분되는 것이다. 검증은 배치·길/벽·건물 여유 검사와 동일 각도 전후 화면이다.
- 기존 #64·#66·#77 / M4: 고정 슬롯, 보행, 조경 정점/배치 수와 체험판 동작을 검수한다. 예상 S. 선행은 위 식재 보완. 완료 조건은 새 고해상도 나무 모델·새 상세 그림자를 추가하지 않고 주요 동선을 유지하는 것이다. 예비 시간과 배포 대기는 별도이며 Epic에 중복 가산하지 않는다.

## 배치

대나무: 약사전 뒤, 대웅전 서쪽·동쪽, 북서쪽 담장의 4군락.
계절나무: 문수전·보현전 사이, 극락전 남쪽, 범종각 뒤, 동쪽 마당의 4군락. 기존 3~5월 봄꽃·6~11월 단풍·12~2월 눈 표현과 연못의 별도 나무는 유지한다.

군락 아래는 공유 저해상도 바닥 텍스처와 낮은 풀을 쓰고, 작은 돌은 걷는 높이·카메라 흔들림에 영향을 주지 않는다. 대나무 개별 겹침 바닥 패치는 군락 단위로 줄인다. 기존 건축·불상·상품의 모델과 재질은 수정하지 않는다.

검수 자료: evidence/woodland-groups/.

## 로컬 검수

원본 단위 검사 80개와 타입·빌드·19개 에셋 기록 검사 통과. 실제 캐릭터로 뒤편 산책길 약 215m를 걸었고 네 전각 참배도 확인했다. 군락의 실제 트렁크 충돌 위치와 메타데이터가 일치하며 주요 길·벽·건물 여유, 중앙 뒤뜰의 비움, 기존 판매 자리 531개의 전체 기록이 유지된다.

같은 1440×1000 로컬 장면에서 전체 정점은 2,599,653 → 2,604,854(+5,201, 약 0.2%), 조경 재질 배치는 7 → 8개다. 나무 수와 단순 모델·거리별 공유 인스턴싱을 유지한다. 이는 정식 성능·모바일 실기기 판정을 새로 내린 것이 아니다. 전후 이미지는 comparison.png와 map-comparison.png, 실제 보행은 walk/check.json에 기록한다.

## 체험판 반영

공개 체험판 v11 반영 완료. 독립 체험판 검사 16개·빌드·에셋 검사 통과. 기존 다섯 아이템 신청/재입장/수행 흐름 통합 검사와 공개 URL의 PC·터치 화면에서 33개 식재 위치·군락 바닥·지도·네 전각 방문/비회원 참배를 확인했다. 페이지 오류·에셋 실패·실제 API 요청은 없었다. GitHub 커밋·푸시는 이번 요청에 포함하지 않았다.
