# M4 비공개 웹 후보 검수

검수 기준은 2026-11-08 승인된 이 Mac의 비공개 웹 후보본이다. Node 24와 PostgreSQL 17을 설치한 저장소에서 `npm ci` 후 `npm run candidate`를 실행하고 http://127.0.0.1:4340/ 에 접속한다. 후보는 서비스 모드로 빌드한 정적 파일을 제공하며, 4330 개발 미리보기와 같은 로컬 시험 DB 및 우편함을 사용한다. 운영 화면은 권한이 있는 시험 계정의 계정 메뉴에서 연다.

## 이슈별 인계

- #64 · Q01~03, Q09. 익명 방문자가 탐방하고 세 법당에서 참배한 뒤 취소·복귀했다. 유료 흐름에서는 다섯 아이템을 신청하고 재방문 시 원래 자리를 확인했다. 폭 320px 및 1440px에서 반짝임 완화, 환경 설정과 계정 창의 키보드 열기·닫기, 초점 복귀를 확인했다. 5명 참가자의 식별 시간 평가는 사용자 결정으로 후속 이관했다. 자동 길 안내는 승인 범위에서 제외했다.
- #65 · Q06. 20계정 동시 신청에서 1명이 예약했다. 중복 주문·늦은 결제 통지, 판매 중지 경합, 설치 실패와 환불 중 재조회, 만료 후 재처리를 로컬 시험 영수증과 대조했다. 환불한 주문에 설치된 아이템은 0개였다.
- #66 · Q04~05. 승인 밀도는 연등 440자리 전체 점유다. 실제 서비스 슬롯 형식의 고정 응답을 사용해 화면 부하를 재현한다. 서버 동시 접속 검수는 #68에서 수행한다. 측정 원본은 evidence/m4-web에 저장한다.
- #67 · Q08. 시험 계정·비소유자·접수·상품·감수 역할의 일반 요청을 대조했다. 공개 철회와 만료 후 공유 문구, 삭제 계정의 시험 우편·공개 문구, 30일 경과 후 주문을 확인했다. 실서비스 개인정보 정책은 출시 전 별도 확정 대상이다.
- #68 · Q07. 독립 인증 세션 20개의 이동·참배, 21번째 방문자의 다른 채널 입장, 순서가 뒤바뀐 이동 통지의 무시, 다른 채널의 공개 철회 및 연결 복귀를 확인했다. 두 Chrome 화면에서 숨김은 2.30초 이내, 만료는 2.29초 이내에 표시가 사라졌다.
- #69 · Q08. `sh scripts/m4-recovery-drill.sh`로 일일 백업 17개 테이블과 531자리의 지문을 대조했다. 별도의 임시 PostgreSQL 클러스터에서 설치 실패·환불·중복 결제·담당자 확인을 재현한 뒤 복원 시점의 설치 권리 지문이 보존됐다. 백업 간격은 서버 가동 중 하루 1회다. 백업 이후 새로 생성된 거래는 그 백업에 포함되지 않는다.
- #70 · F39. 4340 후보에서 시험 이메일 링크로 로그인한 후 결제 취소, 재신청, 결제 화면 종료 후 복귀, 재방문 소유권을 검수했다. 실결제·외부 메일·앱스토어·공개 도메인은 연결하지 않았다.
- #71. 이번 인계 범위는 비공개 웹 후보본까지다. 공개 출시 전에는 운영 호스팅과 도메인, 메일 발송 및 결제 제공자, 실제 판매·환불·개인정보 정책, 운영 담당자와 별도 배포 승인이 필요하다. 종교 감수는 #36에서, 5인 식별 평가는 #64의 후속으로 추적한다.

## 시험 운영

접수 담당자는 /staff.html에서 장애 알림·영수증 상태를 확인한다. 설치 실패는 같은 자리에 재시도하고, 환불이 확인될 때까지 자리를 잠근다. 시험 운영 역할과 로컬 웹 롤백 절차는 [M3 로컬 서비스 운영](../server/service/README.md)에 있다. 복원·롤백 훈련은 격리한 환경에서 실행한다.
