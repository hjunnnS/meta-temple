# 모바일 지도·메뉴·발열 후속 보완

2026-11-20. 사용자 보고: iPhone 14 Pro Safari에서 지도 클릭 시 처음 로딩 화면으로 돌아감, 뒤로·닫기 버튼 사각 테두리, 일정의 반복 KST 표시, 여전한 발열. 기존 M4 / Epic #1·#4·#74의 Implementation #64·#77 후속이다. 예상 작업량 S, 실제 기기 확인과 게시 대기는 별도다. 기존 Issue 번호·승인 상태를 보존하며 새 Issue를 중복 생성하지 않는다. 가격·결제 및 서버 프로토콜은 변경하지 않는다.

## 원인 구분

코드와 Mac WebKit 검수에서 지도 버튼 자체의 페이지 이동/reload 코드는 발견하지 못했다. 실제 iPhone에서 Safari가 메모리 압박으로 페이지를 다시 불러온 것인지, 단순 시점 이동인지는 아직 확정하지 못했다. 사용자 기기의 재로딩/온도/메모리 로그를 수집하지 않았으므로 원인을 확정하거나 실제 기기에서 튕김·발열이 해결됐다고 표시하지 않는다.

확인한 개선 대상은 메뉴를 열어도 배경 3D가 계속 렌더링되는 점, 지도 번호 배치에서 각 SVG 글자 폭을 읽으며 동기 레이아웃을 유발하는 점, 모바일에서도 보존하는 큰 렌더/그림자 설정과 이미 폐기된 건물 제작 객체 참조다.

## 수정

- 모바일 지도·대화상자·접수창을 보는 동안 준비가 끝난 배경 3D 렌더링을 일시 정지한다. 닫으면 다시 시작하며, 참배·명상·108배가 진행 중이면 계속 진행되도록 예외를 둔다. PC는 기존 렌더링을 유지한다. 비동기 메뉴 속성 변경과 화면 복귀를 관찰한다.
- 모바일 기본값은 ‘가볍게’, 기본 프레임 상한은 20fps다. 사용자가 선택한 균형/고품질 설정은 존중하며 고품질만 30fps다. 균형/가벼움의 그림자 대상은 512px, 갱신은 균형 4프레임/가벼움 6프레임 간격이다. 모델·텍스처를 삭제하지 않았지만 모바일 윤곽·그림자·움직임의 표현은 더 가벼워진다. PC 기존 품질은 유지한다.
- 모바일의 폐기된 건물 제작 객체 배열 참조를 정리한다. 숨겨 둔 충돌 보조 객체는 보존하며 기존 충돌/보행 정보를 사용한다.
- 지도는 크기·글자 크기가 실제 변했을 때만 다음 프레임에 재배치한다. 글자 폭은 2D 측정으로 구해 SVG 글자별 동기 배치 읽기를 피한다. 관찰자 해제 시 예약된 작업도 취소하고, 이미 열린 지도는 다시 만들지 않는다. 번호 최소 14px과 기존 장소 선택을 유지한다.
- 모바일 하단 메뉴의 backdrop blur를 제거한다. 뒤로·닫기 아이콘 버튼의 Safari 기본 appearance·테두리·그림자를 제거하고 원형 터치 영역을 적용한다. 터치로 연 메뉴에는 사각 포커스 테두리가 나오지 않으며 키보드 Tab에는 명확한 포커스 표시를 남긴다.
- 매 시간 뒤 KST를 제거한다. 일정창에 ‘한국 시간 기준’을 한 번 표시하며 기존 한국 시간 일정 계산은 바꾸지 않는다. 다른 시간대의 현지 시각 보조 표기도 유지한다. 13개 번역 사전에도 해당 문구를 추가하되 체험판 전용 기존 문구를 보존한다.

## 로컬 검증

- 원본 122개/체험판 61개 단위 검사 통과, 두 소스 빌드 성공.
- iPhone 14 Pro 화면·터치 모의의 Mac WebKit 및 Chrome 각각 지도 열기/닫기 20회와 가로·세로 회전·지도 장소 선택을 완료했다. 두 엔진 모두 페이지 재탐색 0회, 지도 번호 14px 이상이었다. 실제 Safari 강제 종료 재현이라고 주장하지 않는다.
- 1초 표본에서 기본 걷기 20프레임, 지도 0프레임, 메뉴 0프레임, 닫은 뒤 약 20프레임. 수행 진행 중 검사 목적으로 직접 연 대화상자에서도 수행 렌더링은 약 20프레임으로 계속된다. 이 직접 호출은 사용자에게 숨겨진 지도 진입 경로를 추가한 것이 아니다.
- 뒤로·닫기 버튼의 border 0, 터치 outline 없음, radius 50%, native appearance 없음. 키보드 Tab 포커스 outline은 유지했다. 일정창에 KST 없음, 한국 시간 기준 안내 확인.
- 이동 조이스틱의 놓기·멈춤·핀치 줌·메뉴 전환·개인 공간 조작·회전·PC 고품질 회귀 검사 통과. PC 건물·지형 geometry, 재질·생성 텍스처 픽셀/해상도는 기존 공개 v56과 동일하다.
- WebKit의 기존 Colyseus SDK가 Node 전용 WebSocket 형식을 시도했다가 브라우저 방식으로 복구하는 진단 1건은 `sdkDiagnostics`로 별도 보존했다. 그 외 새 페이지 오류는 없었다. 별도 지도 측정 코드의 숨겨진 수행 중 지도 버튼 가정과 체험판 전용 번역 초기 동기화 문제는 게시 전에 수정하고 재검수했다.
