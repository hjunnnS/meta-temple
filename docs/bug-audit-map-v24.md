# v24 체험판 버그 재검수

2026-11-13. 기존 M5 / Epic #1 / Implementation #86의 후속 수정·검수. 기존 #64의 통합 검수 시나리오를 재사용하며 새 기능 Issue를 만들지 않았다.

## 발견하고 수정한 문제

1. 중간 폭 모바일의 지도 목록 가독성: 공개 v24 영어 430px에서 목록 높이 114px보다 버튼이 117px로 커져 문구를 한 번에 읽기 어려웠다. 421~700px 지도 목록을 3열에서 2열로 변경했다. 420px 이하의 한 열 목록은 유지한다.
2. 지도 이동 후 조작 초점 경쟁: 창을 닫는 지연 이벤트가 이동 후 게임 화면에 맞춘 초점을 지도 버튼으로 되돌리는 경우를 로컬에서 재현했다. 이미 게임 화면에 초점을 맞춘 경우 닫기 이벤트가 덮어쓰지 않도록 수정했다. 기존 지도 회귀 검사는 창 닫힘 후 150ms를 기다린 뒤 이동·닫기 각각의 최종 초점을 검증하도록 강화했다.

## 공개 v24 재검수
- 여섯 전각 설명·불보살·대표 기도 주제와 실제 이동: 한국어 PC 및 한국어 포함 14개 언어의 320px 화면, 총 15개 조합 통과.
- 다섯 시험 아이템 신청, 비회원 로그인 후 선택 복귀, 실제 첫 절 기록, 개인 공간 전시 저장·새로고침, 일정·야간·터치 화면 통과.
- 다섯 가이드 코스 PC/터치의 총 10회 실제 참배·무료 완료·코스 변경·자유 보행 통과.
- PC/터치에서 종치기 소리·취소, 차/커피 선택·마시기, 소원동전 3초 카운트, 비질 스님 말풍선·음성, 확장 구역 이동·명상 종료 통과.

## 증거와 한계
공개 버전 검수는 evidence/bug-audit-v24, 수정 후 검수는 evidence/bug-audit-fixed에 기록한다. 검수 범위에서 추가 오류가 발견되지 않았다는 의미이며 무결점을 보장하지 않는다. Chrome의 터치·화면 크기 검수이며 실제 휴대폰, Safari, 실제 Firebase 로그인·PG 결제·50명 동시 접속 검수는 포함하지 않는다. 체험판의 계정·거래 데이터는 시험 데이터다.
