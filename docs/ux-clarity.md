## 기존 Issue에 대응하는 구현 범위

1. M3 / Epic #1 / #35·#36 후속 — 수행 장소 예고. 기존 보행의 실제 수행 목적지를 읽어 버튼에 전각 이름과 행위를 표시하고 이동 전에 시작 장소를 설명한다. 선행: 기존 수행/이동. 완료: 입구에서는 대웅전, 관음전 수행 자리에서는 관음전으로 표시되고 실제 동작과 일치. 검증: PC/터치 실조작. 예상 S.
2. M4 / Epic #1 / #64 및 M5 #81 후속 — 지도 22개 장소를 기도 공간/쉼터·산책/기타 시설로 분류. 분류 버튼을 스크롤 영역 밖에 두고 선택 장소 이름을 지도 아래에 표시. 좌표·도착 위치·기도 주제·기존 ID 보존. 선행: 기존 서비스 지도. 완료: 모든 장소가 한 분류에 있고 분류/지도/목록 선택과 상세·이동 버튼이 일치. 예상 S.
3. M5 / Epic #1 / #79·#81 및 M6 #88 후속 — 이동 단계의 스님 안내만 접기. 목적지·거리·지도·펼치기·안내 종료는 유지. 펼침/접힘을 직접 선택할 수 있고 도착하면 전체 설명과 다음 안내가 복원됨. 선행: 기존 도착 판정. 완료: 접힌 상태로 도착 조건을 우회할 수 없고 코스·단계·기도문 보존. 예상 S.
4. M6 / Epic #1 / #88 후속 — 안내 중 수행 버튼의 기존 비활성을 유지하며 같은 버튼에 안내창에서 선택하라는 짧은 이유 표시. 종료하면 이유와 비활성을 함께 해제. 새 팝업 추가 없음. 예상 S.
5. M3 / Epic #1 / #36 및 M6 #87 후속 — 완료와 중단 문구 구분. 참배/명상/108배 완료는 각 행위 이름으로 표시, 중단은 다시 시작 가능하다는 짧은 안내만 표시하고 완료 효과는 실행하지 않음. 안내 종료 버튼을 안내 종료·자유 탐방으로 명시. 기존 완료 기준·서버 카운트는 변경하지 않음. 예상 S.

다국어는 기존 Epic #74 / M4 #76·#77 후속으로 새 19개 문구를 기존 14개 언어에 연결했다. 체험판 전용 번역은 보존한다. 원어민/종교 감수는 추가하지 않는다. 작업량은 구현 Issue 후속 범위만 산정하며 검수·정책 대기를 중복 합산하지 않는다.

## 검증 결과

- 원본 자동 검사 94/94, 체험판 31/31, 두 소스 타입 검사·빌드 통과. 새 검사는 행위별 완료/중단 문구와 14개 언어의 목적지 자리표시자 보존을 확인한다.

- 기존 22개 지도 마커/장소 유지. 세 분류를 실제 클릭해 선택 장소 설명과 이동 버튼 연결 확인. 모바일 목록 높이 약 194px는 고정 분류 행을 제외한 목록 자체의 높이이며, 이전 114px보다 넓다. 기존 전체 22개 스크롤 목록 대신 선택한 분류만 보여 준다.
