# 조경·종무소·연못 수정 GitHub 보존 기록

## 최종 상태
- 대나무17무리·계절나무16그루를 종류별8군락으로 정리하고 중앙과 전각 진입을 비운다.
- 단풍은 작은 접힌 잎들이 겹친 수관, 대나무는 마디와 가는 잎가지로 보완한다. 기존 계절·거리별 표현 유지.
- 뒤편 산책로 보조등16개, 기준 간격14m. 최종 크기는 최초의80%(높이 약60cm). 가까운 실제 광원은 최대2개, 추가 그림자 맵 없음.
- 종무소는 쉼터와 같은 줄, 출입구는 대웅전 방향. 연못34×19m 유지.
- 목교는 제거했다. 연결로·지도·경사 바닥·난간 충돌도 제거하고 연못 경계석과 전체 U자 동전 구간을 복원했다.
- 531개 판매 자리 전체 기록 유지.

최종 구현 단위 검사83개, 독립 체험판19개·타입/빌드·19개 에셋 기록 검사 통과. 최종 공개 검수는 evidence/pond-no-bridge/published/check.json: 다리 메시/재질 없음, 보조등 상단0.6m·16개 위치, 3초 카운트와 실제 동전 비행, 오류·에셋 실패·실제 API 요청 없음.
