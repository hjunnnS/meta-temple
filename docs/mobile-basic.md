# 모바일 기본 대응 — 기존 이슈 후속 범위

사용자 승인: PC 그래픽을 유지하며 터치 조작, 화면 겹침, 모바일 그래픽 설정을 보완하고 로컬 검수 후 기존 공개 체험판에 반영한다. 가격·결제는 변경하지 않는다. 새 GitHub 이슈/마일스톤 생성이나 기존 승인 상태 변경은 하지 않는다.

## Milestone / Epic / Implementation Issue

M2 / 기존 Epic #1: 모바일에서도 탐방과 개인 공간 조작이 가능하고 PC의 승인된 시각 설정이 유지되는 것이 이번 범위의 완료 조건이다. 날짜는 지정하지 않는다.

- #15 이동: 공용 사찰/개인 공간 터치 스틱, 약한 입력의 저속 이동, 손을 떼거나 포인터 취소·화면 전환 시 정지. 기존 키보드와 바닥 탭 이동을 유지한다. 선행: 기존 이동·충돌 구현. 검증: Chrome CDP 터치 입력으로 좌표 변화·정지·개인 공간 퇴장 후 조작부 제거 확인. 예상 작업량: 중간.
- #16 카메라: 한 손가락 둘러보기, 두 손가락 확대·축소, 기존 벽·천장 충돌 제한을 함께 사용한다. 선행: #15 및 기존 안전 카메라. 검증: 공용/개인 공간 실제 멀티터치 이벤트로 거리 변화, 공용 공간에서 의도하지 않은 회전·신청창 발생 방지. 예상 작업량: 중간.
- #27 화면 설정·접근성: 모바일 기본 균형 품질 및 섬세하게/가볍게 선택, PC와 모바일 설정 별도 저장, 작은 화면/가로 화면의 조작부·메뉴·안내 겹침 완화, 안전 영역과 가상 키보드의 보이는 높이 대응. 선행: 기존 설정·다국어 UI. 검증: 390×844, 844×390, 320×740 및 PC 1280×900. 예상 작업량: 중간.

M4 / 기존 Epic #4 및 번역 Epic #74: #64 통합 동선, #66 그래픽 부담, #76·#77 다국어 화면의 기존 검증 범위를 재사용한다. 실행 항목 작업량만 산정하며 위 #15·#16·#27과 중복 가산하지 않는다. 기기 준비 대기는 별도이며 실기기 검수는 이번 완료 조건에서 제외한다.

## 구현의 경계

- PC 고품질: 해상도 배율 1, 낮 그림자 4096 / 해질녘·밤 2048, 기존 Glow 및 반사 갱신을 유지한다. 기존 PC 가벼운 품질도 유지한다.
- 모바일: 기본 균형 품질. 해상도·그림자 크기·반사 갱신 빈도를 줄이고 Glow 버퍼는 512로 제한한다. 모바일 가벼운 품질에서도 연등 빛남은 끄지 않는다. 건물/아이템 모델, 한지 재질, 색, 설치 자리와 소유권은 바꾸지 않는다.
- 모바일 판별은 화면 폭 단독이 아닌 터치 지원과 coarse pointer를 사용한다. 모바일 설정은 `sasa:display:mobile-quality`, PC는 기존 키에 저장한다.
- 실기기 자동 성능 판정이나 프레임률 보장은 구현하지 않았다. 가상 키보드는 visualViewport 기반 대응이며 실제 iOS/Android 키보드 검수는 후속이다.

## 검수

- 본 서비스 자동 검사 100개, 체험판 자동 검사 37개 및 양쪽 TypeScript/프로덕션 빌드.
- evidence/mobile-basic/results.json: 공용/개인 공간 터치 이동·정지·확대축소, 개인 공간 복귀와 DOM 정리, 모바일 전용 설정 저장, PC 해상도·그림자 유지, 가로 회전 및 JS/네트워크 오류 확인.
- evidence/mobile-basic/small-screen.json: 독일어·러시아어 320px 지도·수행·스님 안내 가로 넘침 검수.
- evidence/mobile-basic/regression/check.json: PC/터치의 기존 바닥 이동, 종치기/소리, 차·커피, 동전 카운트다운, 비질 스님, 확장 구간 이동, 명상 종료 회귀 검수.
- 브라우저 검수는 Mac Chrome의 터치 모의 환경이다. 실제 휴대폰 Safari/Chrome 성능, 발열, 배터리, 키보드는 미검수다.
