# 종무소 정렬과 연못 목교

## Milestone
M2 공간 보완: 종무소를 쉼터와 같은 남북 위치에 두고 대웅전 방향으로 개방한다. 연못을 확대하고 실제 보행 가능한 다리를 연결한다. M4 검수: 동선·접수·소원 동전·고정 슬롯·체험판 확인. 목표 날짜는 지정하지 않는다.

## Epic
기존 E01 공간 구성(#1), E04 웹 검수(#4)의 후속 보완. 포함 범위는 종무소 위치·회전·진입로, 연못 크기, 목교·접근로·지도·충돌/바닥 높이다. 기존 건물·아이템 재질과 모델, 구름탑·쉼터 위치, 531개 판매 자리, 가격·결제·정책은 유지한다. GitHub 새 이슈 생성·상태 변경은 없다.

## Implementation Issue 대응
- 기존 M2 #18·#23 후속: 종무소 중심 z=-46→-70m, 입구 북향, 연못 27×15→34×19m(약 59.5% 면적 증가), 서쪽 목교 폭 2.8m·길이 23.5m·상판 높이 0.78m·양끝 3m 완만한 경사. 선행: 사용자 배치 변경 승인. 완료 조건: 쉼터 정렬·출입 가능·물/탑/테라스 간섭 없음·실제 보행 및 클릭 이동 가능. 검증: 단위 검사, 같은 각도 전후, 실제 보행/접수 검사. 예상 M.
- 기존 M4 #64·#66·#77 후속: PC·터치에서 보행·카메라·접수 유지·동전/지도·에셋/오류 검수. 선행: 공간 보완. 완료 조건: 길 단절·물 위 보행·난간 통과·고정 자리 변경이 없음. 예상 S. 예비 시간·배포 대기는 별도이며 Epic에는 중복 가산하지 않는다.

## 동선 원칙
천왕문 출구에서 동쪽→높은 진입 담 바깥의 남행 길→종무소 앞 마당. 종무소→목교 남쪽 끝→연못 횡단→구름탑 서쪽 접근로. 기존 쉼터 남쪽 접근길은 다리 남단 바깥을 지나 난간과 교차하지 않는다. 다리 위는 소원 동전 신청 위치에서 제외하며 기존 U자 은행의 지상 구간은 유지한다. 넓어진 연못의 기존 맑은 물·8마리 잉어·연꽃·하트 소원함 재질과 연출은 보존한다.

## 검수 결과

원본 82개·독립 체험판 18개 단위 검사, 타입·빌드·19개 에셋 검사 통과. 531개 전체 고정 슬롯 기록 보존. 실제 WASD로 종무소→다리 남단→구름탑 접근로→다리 중앙 복귀, 완만한 높이 전환과 난간 충돌, 마우스 클릭 보행 통과. PC·터치 화면에서 북향 종무소 접수 화면·다리 클릭 보행·야간을 확인했다. 기존 다섯 아이템 신청·설치·재입장·개인 전시·수행 흐름 통합 검사 통과. 오류·에셋 실패·실제 API 요청 없음. 실제 결제나 모바일 실기기 성능을 새로 판정한 것은 아니다.
