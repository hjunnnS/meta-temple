# I02 #6 — 공간과 좌표 계약 제안

## 2026-11-06 사용자 확정 변경 — 이전 조건보다 우선

- 개발·검수 기준은 웹이다. 앱은 후속 검토이며 필요 시 하이브리드 포장을 검토한다. 앱 구현·실측·스토어 결정은 현재 M1 선행 조건이 아니다.
- 현재는 그래픽 품질을 우선한다. 저사양 모바일 최적화·실기기 통과는 후속 검증으로 이연하며 현재 M1을 차단하지 않는다. 웹에서 측정 가능한 성능 기록은 계속 보존한다.
- 사찰 배치는 기존 기획서 구조를 따른다. 배치된 모든 건축 구조물은 출입할 수 있어야 하며 실내가 있는 건물에는 탐방 가능한 내부를 포함한다. 문·누각은 통과/진입 가능한 구조로 구현한다. 석탑 등 내부 공간이 없는 조형물의 인위적 실내를 뜻하지 않는다.
- 전체 배치·실내 제작은 기존 M2 공간 제작 Issue에서 수행한다. M1 샘플을 전체 맵 완성으로 간주하지 않는다. 실행 데이터의 임시 치수·좌표가 원본 기획서를 대체하지 않는다.
- 시각 품질은 사용자가 실제 화면을 본 후 판단한다. 기존 캡처는 검증용 초안이며 승인된 최종 품질이 아니다.


상태: 설계 초안, 공간 책임자 승인 전. `src/contracts.ts`의 `layoutDraft`는 실행 가능한 검증 데이터다. M1 대표 장면의 로컬 원점과 전체 사찰의 원점은 별개이며 실제 설치 데이터로 전환하지 않는다.

## 좌표

1 unit=1m, 왼손 좌표, +Y 위, +Z 북쪽(탐방 진행), 회전 라디안. 전체 맵 원점=중앙 마당 기준점. Z02→Z03→Z04 중심축. 실험 장면 원점 변환은 추후 I21에서 명시적으로 수행하며 샘플 ID는 `sample:` 접두사를 유지한다.

## 12개 공간

Z01 일주문·천왕문(통로), Z02 연등 광장·연등길(외부), Z03 중앙 마당·석탑(외부), Z04 대웅전(공개 실내 제안), Z05 관음전(공개 실내 제안), Z06 지장전(공개 실내 제안), Z07 인등전(공개 실내 제안), Z08 소원패 정원(외부), Z09 추모 구역(외부), Z10 종무소(안내 실내 제안), Z11 범종각(개방형), Z12 명상숲(외부).
각 중심 좌표와 가로·세로 초안은 `zones`에 보존한다. 180×160m 등 과거 가정치를 확정값으로 사용하지 않는다. 시험 데이터 크기는 제작용 제안이며 감수 승인 필요.

## 동선·로딩·카메라

주 동선 Z01→Z02→Z03→Z04. Z03에서 좌우 Z05/06/07/08, 북측 Z09/12, 입구 측 Z10/11로 연결. 공개 공간별 왕복 가능 경로를 확보한다. 사용자 확정에 따라 모든 배치 건축물에 출입 가능한 동선을 확보한다.
보행 규격 제안: 통로 폭 2.4m 이상, 문 유효폭 1.2m 이상, 단차 0.18m 이하 계단과 대체 완만 동선. 로딩 경계는 출입구 바깥, 충돌 준비 전 진입 금지. 3인칭 충돌 카메라와 1인칭 상향 각도는 M2 검증 대상.
V01 진입, V02 연등 바닥면 상향, V03 사람/건축 비례, V04 처마 접근, V05 내 상품, V06 가림/재방문을 고정 구도로 기록한다. 현재 버튼 구도는 V01~V06 전체 검수 완료를 뜻하지 않는다.

## 슬롯

Temple/Zone/Slot ID는 배치 버전과 분리한다. 좌표·회전·상품 호환은 서버 원본. 샘플 100/300/500/1000은 성능 실험량이며 판매 용량 아니다. 연등·인등·소원패·추모등의 실제 수량·간격·크기·호환은 P12 승인 필요. 승인 전 예약/구매 불가. 운영 중 임의 이전 금지; P16 예외 승인 시 별도 변경 계획.

검증: 자동 테스트로 12개 공간 ID·유효 좌표·크기, 샘플 100→1000의 ID/좌표 불변 확인. 현장 동선·건축 고증·슬롯 실제 판매 용량은 미검수.
