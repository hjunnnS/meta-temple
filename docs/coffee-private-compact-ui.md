# 의자 터치와 필요할 때 여는 쉼터·개인 공간 메뉴

2026-11-21. 사용자가 의자 터치 앉기, 주문·개인 공간 메뉴 접기, 수행 정보 유지 및 모바일 검수·체험판 반영을 승인했다. 기존 M4 모바일 UI 후속, Epic #1·#4·#74 / Implementation #39·#64·#77 관련 범위로 진행한다. 기존 번호·내용·승인 상태를 바꾸거나 중복 Issue를 만들지 않는다. 예상 구현량 M, 브라우저 검수·게시 대기는 별도이며 새 목표 날짜는 정하지 않는다.

## 구현 및 완료 조건

- 빈 의자를 터치하면 기존 경로 찾기로 접근한 뒤 방향 전환·앉기를 수행한다. 선택한 자리를 작은 바닥 테두리로 표시한다. 드래그·핀치와 클릭 판정을 공유해 둘러보기 중 실수로 앉지 않게 한다. 보이지 않는 넓은 터치 판정 영역을 사용하며 의자 모델은 바꾸지 않는다.
- 앉은 뒤에는 작은 `커피 주문`·`일어나기` 버튼만 표시한다. 쉼터에 접근하거나 앉는 것만으로 주문창이 열리지 않는다. 주문 버튼을 누를 때만 음료 선택창을 열고 닫기·바깥 터치·Escape로 닫을 수 있다. 음료를 선택해 마시면 창을 닫고 앉은 상태를 유지한다. 주문 전에는 컵을 표시하지 않는다. 기존 음료 체험이며 가격·결제는 변경하지 않는다.
- 개인 공간은 평소 `공간 메뉴` 버튼 하나로 기능을 모은다. 절하기·명상·1인칭·풍경·아이템·설정과 사찰 복귀를 필요할 때 연다. 기능 선택 시 메뉴를 접고, 수행 중에는 기존 수행 상태창의 상태·시간·마치기 버튼을 유지한다. 별도의 하단 수행 버튼 줄을 중복으로 띄우지 않는다.
- 공개 사찰의 자동 108배·진행 시간·횟수·중지/계속 기능은 유지한다. 개인 공간의 기존 절하기·명상 로직도 유지한다.
- 모바일 주문 버튼과 공간 메뉴 버튼을 조이스틱 옆의 빈 영역에 배치하고, 짧은 화면에서는 메뉴 안을 스크롤할 수 있게 한다. 새 문구 3개는 기존 13개 번역 사전에 함께 추가했다. 체험판 전용 기존 문구는 보존했다.

의자 사용 여부는 현재 장면의 방문객 위치를 확인하는 보조 판정이며 별도의 서버 좌석 예약·결제 기능을 추가하지 않는다. 기존 건물·캐릭터·움직임·모바일 그래픽 예산은 유지한다.

## 검증

- 정식 저장소 단위 검사 135개와 체험판 74개, 두 빌드 통과.
- Mac WebKit·Chrome에서 iPhone 14 Pro 터치·화면 크기를 모의하고 PC Chrome에서도 검사했다. 실제 의자 터치, 드래그 시 앉지 않기, 앉기·일어나기, 주문창의 요청 시 열기·닫기·마신 뒤 닫기와 착석 유지, 개인 메뉴 요청 시 열기·선택 후 접기·1인칭 전환·사찰 복귀를 검증했다.
- 모바일 393×852, 작은 화면 320×740, 가로 852×393 조건에서 조이스틱 겹침·가로 넘침과 수행 정보 표시를 확인했다. 명상 시간 증가와 메뉴 밖 상태창·종료 버튼, 모바일 108배 1회 완료 후 `1 / 108` 표시를 확인했다.
- 기존 자동 108배의 실제 반복·일시정지 시 횟수/타이머 정지·계속하기·취소 및 108회 경계 검사를 통과했다. 경계는 시험용 107회 시작 응답을 사용했으며 전체 108회 실시간 수행을 뜻하지 않는다.
- 한국어 WebKit·모바일 Chrome·PC Chrome의 전체 흐름과 프랑스어 모바일 Chrome의 동일 흐름을 통과했다. 프랑스어처럼 문구가 긴 경우에도 320px 화면에서 조이스틱과 주문·공간 메뉴 버튼이 겹치지 않는 것을 검사했다. 초기 자동 검사의 화면 밖/버튼 뒤 의자 좌표와 다음 프레임 전 HUD 판정은 검사 좌표·대기 조건을 바로잡아 재실행했다. 제품 오류로 판정하거나 실패를 통과로 고쳐 쓰지 않았다.

검사 스크립트는 `scripts/check-compact-rest-ui.mjs`, 원시 결과와 화면은 `evidence/compact-rest-ui/`에 저장한다. 실기기 iOS Safari·온도 측정은 이번 검사에 포함하지 않는다. 기존 WebKit의 WebSocket 생성자 fallback 진단은 별도로 보존한다.

## 체험판 반영

60버전 배포 성공. 배포 소스는 `1362c19aa9cb01d0fe3398c9479f9937b7cfff5a`이며 Mac 공유 서버의 정적 파일도 같은 빌드로 반영했다. 공개 주소의 WebKit·모바일 Chrome에서 의자 터치·드래그 구분·주문창 요청 시 열기·착석 유지·개인 메뉴 접기·명상 시간·모바일 108배 횟수·사찰 복귀 검사를 모두 통과했다. 결과와 화면은 `published/`, 게시 정보는 `publication.json`에 있다.
