# I06 #9 — 제작·감수·사용권

상태: 절차 초안 / 종교·건축 감수 담당과 최종 미술 기준 승인 대기.

## 이번 샘플 출처

- 건축·기와·연등·나무: `src/scene.ts`에서 직접 생성한 형상. 외부 모델/사진/음원 다운로드 없음.
- 단청·연등 패턴: 동일 파일의 Canvas2D 직접 작성 패턴. 특정 사찰 단청 복제 또는 전통 문양 고증 완료 주장 없음.
- 글꼴: 운영체제 기본 serif/sans-serif 사용, 폰트 파일 재배포 없음.
- 한자 현판 `大雄殿`: 명칭 표시 샘플. 사찰 제휴/고증 인증 표지 아님.
- 무음: 음원 권리 문제가 검토되지 않은 상태에서 임의 음원을 포함하지 않음.
- Babylon.js: npm 고정 버전, 배포 시 라이선스 고지 유지. 종속성 잠금은 package-lock.json.

## M2 제작 검사

모델마다 작성자·원본 URL·라이선스·상업 사용·변형·재배포 권리·버전·감수 여부를 기록한다. 출처가 확인되지 않은 파일은 제작 파이프라인에 반입하지 않는다. 사용자 소유 참고 이미지도 서비스에 복제할 권리가 자동 부여되는 것은 아니다.

대표 외관은 기단/계단/처마/기둥/단청/기와가 구분되어야 한다. 단청은 단순 장식 색상과 문양 고증을 구분한다. 연등은 줄·고정점·바닥면·표면 무늬가 보이고 발광 때문에 문구가 지워지지 않아야 한다. 모든 신규 자산은 I01 승인 재질/예산을 따른다.

## 필요한 담당 결정

P08 종교·건축 감수 담당은 서비스 책임자가 지정한다. 모델·문구·법당별 의례·불상 표현은 담당 검토 후 확정. 현재 불상·의례 동작을 임의 구현하지 않았다. 기본 아바타 비례·외형 P15는 M2 전에 확정한다. 채팅·커스터마이징은 제외.

제안 승인 순서: M1 기술 장면 검토→수정 요구 기록→승인된 엔진 캡처 기준선→M2 대표 구간 확대 검수. 현재 캡처는 미승인 샘플이다.

## 현재 검수본

법당과 각 보살상·범종·당목은 저장소의 절차형 모델이다. 독립 얼굴 비교 도구는 사용자가 선택한 로컬 사진을 브라우저에서만 연다. 참고 사진 원본과 이를 포함한 비교 캡처는 검수 빌드 및 GitHub 검수 자료에서 제외한다. 재질의 원본·라이선스 목록은 asset-credits.md에 둔다. 사용자가 마무리한 한지 연등과 사찰 전체의 종교 고증 승인은 별도로 기록한다. 종교 감수 담당 지정과 법당별 도상 검토는 미결이다. #14 반입 검수와 #21 불단 최종 검수에서 확인한다.

기본 아바타 제작 제안은 성인 직립 1.7m, 통과 여유를 포함한 폭 0.65m이다. 대웅전의 절 자리 1.05×1.85m와 비교하여 충돌체와 절 동작이 이웃 자리를 침범하는지 #15·#36에서 확인한다. 단일 기본 복장과 서기·걷기·합장·절하기를 우선 검토하며 아바타 최종 외형은 별도 감수 대상이다.
