# 108배 연속 수행

- 기존 M3 / Epic #1 / Implementation Issue #36 후속 개선. 새 Issue·가격·결제 정책 변경 없음.
- 구현 범위: 시작 1회로 108배 반복, 현재 절이 끝난 뒤 일시정지, 같은 세션 계속하기, 그만하기, 108회 완료 후 자동 종료. 기존 로그인·기록·취소 API와 빛 효과 유지.
- 선행: 기존 수행 상태·횟수 표시 및 사용자 승인. 예상 작업량 S.
- 완료 조건: 완료된 절의 응답을 확인한 뒤 다음 절을 시작하며 중복 요청·109회 진행이 없어야 한다. 정지 중에는 횟수와 수행 시간이 멈추고, 중단·이동 후 반복이 남지 않아야 한다.
- 검증: 기존 단위 검사 및 빌드, 실제 UI에서 자동 반복·일시정지·시간 정지·재개·중단·카메라 유지. 108회 경계는 시작 응답 107회 시험 데이터로 검증하며 실제 108회 전부를 기다리는 검수와 구분한다.
- 기존 부드러운 절하기 동작은 유지한다. 매 회 서버 확인을 기다려 통신이 늦어지면 다음 절도 대기한다.
