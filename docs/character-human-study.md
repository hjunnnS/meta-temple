# 사람형 캐릭터 비교용 시제품

> 아래는 비교 시제품 단계의 기록이다. 이후 사용자 승인으로 전체 사찰에 적용했다. 현재 상태와 최종 검수는 [공통 캐릭터·방문객 행동](characters-and-ambient-actions.md)을 따른다.

## 작업 관리
- Milestone: M2, Epic #1, 기존 Implementation Issue #15의 외형 보완 검토. M3 #36의 절·명상 동작과 M4 #64·#66의 화면 검수를 연결한다. 기존 이슈 상태를 변경하거나 새 이슈를 생성하지 않았다.
- 범위: 기존 사람형 한 명과 새 사람형 한 명을 동일 조명·동작으로 비교하는 실제 3D 화면. 둥근 얼굴, 눈·눈썹·코·귀, 옆으로 흐르는 머리, 작은 손, 겹치는 소매, 신발을 구현한다.
- 제외: 본 서비스 방문자·스님·가상 방문객·12지신 일괄 교체. 가격·결제 변경.
- 선행 조건: 기존 승인된 절하기 리그와 사용자 제공 외형 참고 이미지. 전체 교체는 비교 결과 확인 후 별도 진행한다.
- 완료 조건: 정면·비스듬히·옆면·얼굴 확대, 법복, 합장·절·명상 비교가 가능하고, 절 접지와 모바일 화면에서 동작한다.
- 예상 작업량: 구현 및 검수 M 1건. 기존 Epic·Milestone 작업량에 중복 가산하지 않는다. 목표 날짜 없음.

## 구현 및 확인
- /character-study.html에 비교 페이지를 추가했다. 실제 사찰의 캐릭터 생성 함수는 변경하지 않았다.
- 같은 기존 관절 리그를 사용하며 절할 때 발목 역회전으로 신발 바닥 관통을 보정했다.
- 최저점: 절의 손바닥 0.0118m, 얼굴 0.0091m, 신발 밑창 약 0.00645m. 시작·합장·무릎꿇기·엎드리기·일어서기·완료 구간을 확인했다.
- 렌더링 오류 없이 비교 동작·법복·명상을 확인했다. 모바일 크기 390×844에서 가로 넘침 없이 터치 조작을 확인했다. 실기기 성능 측정 결과는 아니다.
- 새 모델 18,420 삼각형, 현재 모델 20,946 삼각형(법복 포함, 숨겨진 구성 포함). 동일 리그 한 명의 지오메트리 비교이며 전체 사찰 FPS를 보장하는 수치는 아니다.
- 단위 테스트: 본 저장소 104개 / 체험판 41개 통과. 양쪽 TypeScript 검사·프로덕션 빌드 및 체험판 자산 검증 통과.
