## 화면 배치

- 사찰 안에서는 현재·다음 일정과 장소별 상호작용을 필요한 때 표시한다. 데스크톱의 상시 방향 버튼은 숨기고 터치 화면에서는 하단 메뉴 위에 둔다.
- 공간 선택은 16개 주요 목적지만 보여준다. 전체 시험 카메라 목록과 성능 측정은 설정 안에서 계속 사용할 수 있다.
- 접수 서랍은 기존 상품·자리·문구·시험 주문 요소를 그대로 담는다. 닫기는 화면만 닫으며 임의로 거래를 취소하지 않는다.
- 개인 공간에서는 사찰 공통 메뉴를 숨기고 절·명상·전시·나가기 및 설정을 모은다. 공간 감상 시점은 펼쳐서 선택한다.
- 소리·화질·시간대·점멸 줄이기·언어 설정은 유지한다. ‘내 아이템 찾기’는 추가하지 않는다.
