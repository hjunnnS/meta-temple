# 개인 공간·스님 대화·쉼터 후속 보완

기존 Milestone/Epic/Implementation Issue의 후속 범위로 처리하며 신규 이슈를 생성하거나 기존 승인 상태를 변경하지 않는다. 가격·실결제는 보류한다.

- M2 / Epic #1 / #27: 첫 방문 안내를 내용에 맞는 작은 카드로 표시한다. 터치 화면에서도 버튼과 본문만큼의 높이를 사용한다. 선행: 기존 안내 유지. 예상 S.
- M3 / 기존 개인 공간 F02·NPC 상호작용: 풍경 선택과 시점 전환을 분리한다. 기본 3인칭과 직접 걷기를 유지하고, 명시적으로 1인칭을 선택한 동안에만 캐릭터를 숨긴다. 전시·수행·저장·재입장 기능을 유지한다. 선행: 현재 개인 공간 구현. 예상 M.
- 같은 기존 NPC·쉼터 범위: 기존 안내/비질/일상 스님 기능은 유지하고 대웅전·쉼터·산책 스님에게 클릭 대화를 추가한다. 자동 인사는 가까운 한 명만, 짧게·간격을 두어 표시한다. 쉼터 직원과 준비 장비를 배치하며 음료 선택은 기존 무료 체험에 연결한다. 예상 M.
- M4 / Epic #4 / #64·#66: PC·터치 모의에서 설명창 높이, 스님·직원 클릭, 창밖 선택 후 캐릭터 유지, 1/3인칭 전환, 실내 벽 가림, 한강 양옆·아래 풍경, 재입장을 검수한다. 예상 S. 실기기 검수·참가자 평가는 이번 범위가 아니다.

완료 조건: 안내 높이 과다 없음, 대화와 기존 수행 충돌 없음, 실내 벽에 야경 발광이 겹치지 않음, 강변 길이 땅 위에 있고 수면/육지 경계가 이어짐, 풍경 선택이 강제 무인 관람 시점으로 바뀌지 않음. 브라우저 검수 증빙은 evidence/room-ux에 저장한다.

검수 결과: 원본 단위 테스트 120개, 체험판 59개 통과. PC·터치 모의에서 안내 높이, 네 인물의 실제 클릭 대화, 여섯 풍경 선택, 1/3인칭 전환·방향 유지, 실내 발광 가림, 수행 종료·전시 화면 복귀·풍경 재입장 유지 확인. 별도 여섯 풍경 반복 생성/해제 검사도 통과. 신체 모델/건물/판매 아이템의 기존 디테일은 유지했다. 새 임시 대화는 브라우저 음성 사용 가능 여부에 따라 음성이 제공되며 말풍선/대화문은 항상 표시한다.
