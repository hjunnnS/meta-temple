# 방문객 이동·체험 순환과 보이는 화면의 정지 개선

## 작업 관리
- Milestone M3 / Epic #3 / 기존 Implementation #53 후속: 방문객의 이동·체험·재이동, 양보·충돌 회피. M2 Epic #1 #15의 승인된 외형·절하기·12지신은 유지한다.
- Milestone M4 / Epic #1·#4 / 기존 #64·#66 후속: 공개 체험판 근접 재현, 실제 표시 모델과 가시성 검사, 모바일·개인 공간·인원 조절 회귀와 영상.
- 선행: 캐릭터 적용본과 기존 20개 배치 후보. 완료 조건: 활성 방문객의 이동과 체험 복귀가 화면에 보이고, 초점이 없어도 보이는 미리보기는 움직이며, 숨김/화면 밖에서는 멈춘다. 예상 구현 M + 검수 S, 대기·배포 시간 별도. 새 이슈·날짜·정책·가격·결제 변경 없음.

## 수정 전 공개 체험판 확인
공개 v34의 가까운 연등길·산책길·대웅전 방문객을 각각 약 9초 촬영했다. 이 검사에서는 전부 정지하는 현상은 재현되지 않았다. 실제 표시 메시의 최대 위치 변화는 각각 약 0.56m, 3.89m, 0.55m였다. 좌표만이 아니라 활성 표시 메시의 위치도 비교했다. 대부분은 제자리 동작이라 정적으로 느껴지며, 기존 렌더링은 document.hasFocus가 false면 보이는 화면도 멈췄다. 먼 곳은 고정 자세를 합친 모델로 교체했다.
근거: evidence/visitor-journeys/before/result.json 및 before/recording.

## 변경
- 초점 조건을 렌더링 실행 조건에서 제외했다. 문서 숨김, pagehide 또는 캔버스의 화면 밖 상태에서는 중단하며 다시 보이면 재개한다. 보이는 화면의 초점 상실 상황은 브라우저 검사에서 모의했다.
- 전신 고정 자세 원거리 모델을 제거하고, 같은 관절 모델의 동작을 유지한다. 가까운 곳은 약 25Hz, 먼 곳은 약 8Hz로 행동을 갱신한다. 건물·아이템·캐릭터 모델 및 그래픽 품질 설정은 변경하지 않았다.
- 20개 배치 후보 중 대웅전 명상 방문객 한 명을 제외한 19개 후보에 목적지를 부여했다. 실제 방문자 한 명일 때는 기존 규칙에 따라 가상 19명 표시이며, 그중 18명이 순환하고 1명은 명상한다.
- 연등길: 걷기 → 연등 올려다보기 → 잠시 쉬기 → 다시 걷기.
- 전각: 기존 방석의 참배/명상 → 자연스럽게 일어서기 → 통로 이동 → 참배 또는 휴식 → 방석 복귀. 지장전은 불단 옆의 막힌 지점을 피한다.
- 소원패·인등전·연못·쉼터·석상·구름탑·뒤 산책길에는 장소별 감상·합장·스트레칭·휴식 목적지를 둔다. 시간차로 시작한다.
- 사용자와 다른 방문객에 약 0.7~0.9m 이내로 접근하면 양보하고, 막히면 경로를 다시 찾는다. 바닥 높이·단차·건물 충돌은 실제 보행 판정을 재사용한다. 도달할 수 없는 지점을 도착한 것처럼 처리하거나 순간이동하지 않는다.

## 검증
- 순환 검수에서는 검사용 시계를 가속해 여러 번 이동·체험·복귀를 검사했다. 모든 활성 순환 방문객이 1m 이상 이동했고 목적지 2회 이상 도착한 방문객이 15명 이상이었다. 최종 검사에서 도달 불가 목적지는 없었다. 표시 중 초점이 없는 조건에서도 시간이 계속 진행됐다.
- 일반 속도 영상은 가속 검수와 별개로 기록한다.
- 원본 107개·체험판 46개 단위 검사, 양쪽 타입 검사/빌드와 체험판 정적 자산 검사.
- 인원 19→10→0→19, 개인 공간에서 숨김/귀환, 모바일 크기 얼굴 선택·가로 넘침 검사. 실휴대폰·실외부 다인 서버 검수는 아니다.
- 결과: evidence/visitor-journeys/after/result.json, regression/result.json, published 영상과 배포 기록.
