# M5 G01 / #78 — 시험 안내 코스

2026-11-13 등록 및 개발 승인. Milestone #5, Epic #1. 구현 #78~#85이며 실행 순서를 유지한다. 정식 종교 감수·사용자 건강 코스 시각 검수·G06의 나머지 코스 검토는 별도 기록한다.

건강은 약사전/약사여래불, 가족은 관음전/관세음보살, 시험은 문수전/문수보살, 관계는 보현전/보현보살, 상실은 지장전/지장보살을 이용하는 시험안을 정리했다. 이는 본 서비스의 체험 구성 제안이며 모든 사찰의 고정 의례 또는 보편적인 고민별 배정 규칙을 뜻하지 않는다. 건강 외 네 코스는 #83 선행 검토 전에는 활성화하지 않는다.

공통 흐름: 자유 탐방/안내 선택 → 고민 선택 → 마음 준비 → 직접 걸어 기존 전각의 수행 자리로 이동 → 스님의 기도문과 함께 짧은 참배 → 선택 수행(절·명상·108배, 생략 가능) → 선택 연등(무료 과정과 분리, 생략 가능) → 마무리. 무료 기도·참배만으로 완료 가능하다. 108배는 기존 계정 인증 후 현재 수행 자리에서 실행하고, 유료 자리 예약 때만 기존 예약 로그인으로 연결한다.

건강 시험 기도문: “몸과 마음이 평안하고, 힘든 시간을 지나가는 동안 용기를 잃지 않기를 바랍니다.” 특정 치료 효과나 시험 합격 등을 보장하지 않는다. 정식 종교 감수는 후속 #36의 기존 상태를 보존한다.

참배 단계에서는 불단과 같은 실내 바닥의 수행 자리에 실제로 도착해야 한다. 카메라로 들여다보거나 벽 밖·지면 높이에서 가까워지는 것은 도착으로 처리하지 않는다. 수행 완료는 실제 동작/서버 결과로 판단하고, 건너뛰기는 별도 결과로 기록한다. 진행은 현재 방문의 메모리에만 두며 고민 입력·이력을 서버나 분석 로그에 보내지 않는다.

참고: 한국학중앙연구원 [삼존불](https://encykorea.aks.ac.kr/Article/E0026810)의 문수·보현 상징 및 약사전·관음전 봉안 설명, 사찰 청량사 [불상의 종류](https://cheongryangsa.org/board/bbs/board.php?bo_table=bubgong01&wr_id=6)의 약사여래·관세음·문수 설명을 대조했다. 이 근거는 위 서비스 코스의 종교 감수 승인이나 효과 보증을 대신하지 않는다. 문구는 새로 작성한 시험 대본이다.
