# 좌측 상단 실시간 접속자 표시

기존 M3 / Epic #3 / Implementation #53·#54의 방문자 상태 표시와 M4 / Epic #1 / #64, Epic #74 / #77의 화면·다국어 검수에 해당하는 후속 보완이다. 새 Issue와 날짜를 만들지 않는다. 예상 S이며 정책·외부 준비 대기는 없다.

- 범위: 로고 옆 작은 반투명 표시와 초록 점, `3명 접속 중` 형태의 인원. 같은 채널의 실제 방문자만 본인·비회원 포함으로 센다. 가상 방문객과 스님 NPC는 제외한다.
- 선행: 기존 Colyseus snapshot의 self/count. 별도 조회 API나 주기적 인원 요청을 추가하지 않는다.
- 완료 조건: 입퇴장·채널 이동에 따라 실제 인원 변경, 미연결 중에는 임의 숫자를 표시하지 않음, 네트워크 단절 시 재연결 표시와 복구, 개인 공간에서 숨김·사찰 복귀 후 복원. 로고·메뉴·일정·수행 패널을 가리지 않으며 기존 14개 언어에서 표시한다.
- 검증: 독립 Chrome 3개로 1→2→3 및 퇴장·단절 복귀, AI17명이어도 실제 방문자는3명으로 표시, 320/390px 세로 및 740×320 가로에서 로고·메뉴 경계, 개인 공간 왕복. 증거는 evidence/online-visitors에 기록한다.

단절 검사에서 브라우저의 offline 통보 뒤에도 기존 WebSocket 표시가 남는 경우를 확인해, offline/online 이벤트에서 기존 연결을 정리하고 복구 시 새 서버 snapshot으로 돌아오게 했다. 기존 가격·결제·그래픽·채널 정원은 변경하지 않는다.

최종 검수: 로컬 및 공개 Sites v42의 독립 브라우저 3개에서 인원 증감·단절 복귀·개인 공간 숨김/복귀 통과. 좁은 화면 3종과 실제 coarse-pointer 모의 가로 화면의 로고/메뉴 경계 확인. 원본 110개·체험판48개 단위 검사 및 양쪽 빌드 통과. 게시와 화면 증거는 evidence/online-visitors/publication.json 및 published에 보관한다.
