# PC·모바일 메뉴 시인성 점검

2026-11-20, 공개 체험판 v53 기준. 먼저 사용자 요청한 최적화·공유 서버 수정·3개 브라우저 검수 자료를 GitHub 원본 fd5fc8f와 체험판 보관본 29d06a3에 커밋·푸시하고 원격 SHA 일치를 확인했다. 이후 메뉴 점검을 진행했다.

이번 점검은 기존 M4 / Epic #1·#4·#74 / Implementation #64·#66·#77 후속이다. 예상 검수 S이며 브라우저 대기는 별도다. 새 Issue나 목표 날짜를 만들지 않고 기존 번호·승인 상태를 보존했다. 이번 메뉴 점검에서는 제품 코드·가격·결제·체험판 게시본을 변경하지 않았다.

## 확인 범위와 결과

- PC 1440×900, 모바일 390×844·320×740 세로와 740×320 가로의 Chrome 터치 모의. 실제 iPhone Safari·Android 실기기·소프트 키보드는 미검수다.
- 각 화면에서 35개 메뉴·상태, 총 140개 화면·상태를 확인했다. 언어/입장, 첫 안내, 하단 메뉴, 지도, 수행 선택, 내 모습·12지신, 전체 메뉴, 일정, 고민 선택·가이드, 다섯 아이템 접수/연등 자리, 계정 전후, 환경 설정, 검수 도구, 종·쉼터·동전 조작, 개인 공간·풍경·전시·명상, 108배 상태·중단 확인, NPC 대화를 포함한다.
- 스크린샷과 실제 글자 크기, 가로 넘침, 버튼 크기, 스크롤 후 화면 중앙에서 실제 클릭을 받는 요소를 확인했다. 일반 스크롤로 볼 수 있는 항목을 가림 결함으로 판정하지 않도록 가운데 정렬로 한 번 더 확인했다.
- 전체 메뉴·수행·내 모습·계정·설정·일정·가이드·NPC 대화·개인 공간의 기본 글자와 버튼은 대체로 읽기 쉬웠고 점검한 경로에서 페이지 예외는 없었다. 다만 아래 문제 때문에 모든 메뉴가 정상이라고 판정하지 않는다.

## 우선 보완할 부분

1. **작은 모바일의 연등 줄 선택과 이동 조이스틱이 겹침.** 320×740에서 줄 1·4·7 등 왼쪽 열 버튼의 가운데가 `public-touch-stick`에 가려졌다. 접수창이 열린 동안 이동 조작을 숨기는 보완이 우선이다. 관련 기존 범위는 #39·M4 #64다. 증빙: `evidence/menu-visibility-v53/small/offering-lantern.jpg`.
2. **모바일 가로 접수창의 고정 확인 버튼이 다른 항목을 덮음.** 740×320에서 소원패·인등·추모등·봉헌초 접수의 기간 선택·빈자리 자동 선택·취소·내 예약 확인 등이 해당했다. 별도 재현에서 ‘내 예약 확인’의 중앙을 가리킨 실제 요소가 ‘신청 내용 확인’ 버튼인 것을 확인했다. 접수창의 스크롤 영역과 고정 하단 영역을 분리하는 보완이 우선이다. #64·#77 후속 범위이며 가격·기간 정책 변경과는 별개다. 증빙: `landscape-reservation-covered.jpg`, `overlap-reproduction.json`.
3. **지도 안 번호가 작음.** SVG 배율을 적용한 실제 표시 크기는 PC 약 7.24px, 모바일 약 2.95px였다. 아래 장소 목록과 선택 장소 문구는 읽을 수 있지만 지도 번호를 읽고 찾기는 어렵다. 지도 표시 높이/확대 또는 번호 표현 개선이 필요하다. 관련 범위 #77. 증빙: `small/map.jpg`, 각 화면의 `result.json`.
4. **PC 연등 자리의 보조 상태 글자가 작음.** ‘선택 가능’ 등의 상태 표시가 10px였다. 모바일에서는 기존 가독성 규칙으로 커지지만 PC도 12~14px 수준의 보완을 권장한다. 관련 범위 #77. 증빙: `pc/lantern-seats.jpg`.

일부 흐린 보조 문구의 계산 대비는 약 4.41~4.46:1로 소폭 낮았다. 불투명 배경에만 계산을 적용했으며, 반투명 UI와 움직이는 3D 배경에 대해 정식 접근성 통과를 주장하지 않는다. 우선순위는 실제 터치를 막는 두 겹침, 지도 번호, PC 보조 글자 순이다.

## 점검 도구 보정과 제한

도구의 첫 실행에서는 전시 메뉴의 옛 선택자, HUD의 즉시 종료 버튼을 중단 확인창 경로로 잘못 가정한 부분, 체험 시작 직후 계정 갱신을 기다리지 않은 부분이 있었다. 제품 코드 변경 없이 실제 선택자·별도 중단 버튼·명시적 계정 닫기로 수정해 누락 구간을 다시 확인했다. 최종 네 화면 모두 35개 상태를 완료했고 페이지 예외는 0건이다. 도구 초기 실패는 제품 결함과 구분해 보존했다.

대량 자리 버튼은 크기·글자는 모두 수집하되, 스크롤 후 실제 가림은 처음/중간/끝을 포함한 표본으로 검사했다. 이번 점검은 한국어 메뉴 중심이며 원어민 번역 평가나 전체 14개 언어 재검수가 아니다. 예약·결제 버튼은 화면만 확인하고 예약·결제를 실행하지 않았다. 화면 크기 모의를 실휴대폰의 터치 감도·발열·성능 검증으로 대신 표시하지 않는다.

요약과 원시 측정은 `evidence/menu-visibility-v53/summary.json`, `result.json`, 각 화면 폴더에 있다. 재현 도구는 `scripts/check-menu-visibility.mjs`이며 기본 실행과 `AUDIT_TAIL_ONLY=1` 후속 구간 실행으로 전체 범위를 확인한다.
