# 입장 준비·버튼 반응·모바일 가독성 보완

2026-11-20 사용자 승인 범위. 기존 M4의 Epic #4 / Implementation #66(로딩·반응), Epic #74 / Implementation #77(다국어 UI) 후속이며, Epic #1 / #64의 기존 동선을 회귀 검수한다. 새 Issue를 중복 생성하거나 기존 승인 상태를 변경하지 않는다. 예상 구현 M, 검수 S이며 브라우저 실행·게시 대기는 별도다. 목표 날짜는 추가하지 않는다.

## 범위와 완료 조건

- PC의 초기 장면 준비를 분할해 입력·화면 갱신 기회를 보장한다. 기존 고품질 설정, 건물·조경 정점, 재질·표면 픽셀과 해상도, 방문객 수를 유지한다.
- 입장 준비 상태·실제 경과 시간을 표시하고, 중복 시작을 막으며, 네트워크 실패 시 언어 선택과 새로 불러오기로 복구한다. 번역·모듈 다운로드를 포함한 입장 대기에는 45초 상한을 적용한다. 장면 준비의 기존 30초 제한은 유지한다.
- 모바일 본문은 1rem, 주요 버튼·상태는 최소 .875rem로 유지한다. 짧은 가로 화면에서도 글자를 줄이는 대신 안내창 너비·스크롤·줄바꿈을 사용하고, 보조 체험판 표시가 안내·하단 조작을 가리지 않게 한다.
- PC 첫 방문/재방문, 느린 CPU의 준비 중 입력, 320×740·390×844·740×320 터치 모의, 14개 언어, 입장 실패 복구, 기존 PC/터치 동선, 원본·체험판 빌드를 검증하고 동일 체험판에 반영한다.

선행: 사용자 승인된 v51 기능·그래픽과 기존 검수 도구. 가격·결제, 외부 계정 설정, 운영 서버 변경, 실제 참가자 평가와 실휴대폰 검수는 이번 범위에 포함하지 않는다.

## 원인과 변경

- 기존 입장 화면은 두 프레임 뒤에 큰 3D 장면을 동기적으로 만들었다. 공개 v51 점검에서 일반 PC 모의 10.056초, CPU 4배 감속 18.174초가 걸렸고, 가장 긴 단일 작업은 각각 4.103초·11.627초였다. 준비 도중 보낸 언어 클릭의 전달 완료는 별도 검사에서 8.547초 지연됐다. 모든 PC의 결과로 일반화하지 않는다.
- 건물 복사·재질별 병합, 조경과 산책길 마스크, NPC 생성 등을 협력적으로 나누었다. scheduler.yield가 없는 브라우저에서는 타이머로 다음 작업에 양보한다. 실행 순서와 최종 형상을 보존하고, 장면이 완성되기 전에는 플레이를 시작하지 않는다.
- 곧바로 스캔 재질로 교체되던 임시 나무·돌·지붕 표면 생성 3회를 제거했다. 유지하는 불투명 절차 표면의 복사는 GPU→CPU 읽기 대신 동일 크기 캔버스 복사를 사용한다. 공개본과 수정본의 최종 정점·법선·면 인덱스·색상·텍스처 설정·생성 픽셀이 일치함을 별도 확인했다.
- 장면 준비 Promise를 모듈 평가와 분리하고 시작 Promise를 한 번만 만든다. 실제 준비 단계에 맞춰 진행 막대를 갱신하며, 마지막 재질 준비는 불확정 상태로 표시한다. 가짜 완료 퍼센트를 표시하지 않는다.
- 언어/모듈 오류와 시간 초과 시 입장 버튼뿐 아니라 언어 버튼도 다시 활성화한다. 선택 언어를 보존해 새로 불러온 뒤 다시 입장할 수 있다.
- 기존 모바일의 접속 상태 11px, 가로 하단 버튼 12px, 안내문 13px, 일부 보조 표시 9px 규칙을 주요 UI에서 덮어썼다. HTML 조작 글자는 rem을 사용하고 브라우저 글자 크기 설정을 따른다. 3D 렌더링 해상도는 UI 글자와 분리돼 있다.

## 로컬 검수

환경: Chrome / Mac, 20Mbps·80ms 네트워크 모의. CPU 감속과 터치 화면은 모의이며 실제 저사양 PC나 휴대폰 결과가 아니다.

- 첫 방문 5.911초·재방문 4.701초. 기존 15초·5초 기준 통과. 가장 긴 초기 작업은 204ms·231ms. 공개 서버 이전 수치와 직접 동일 환경 비교로 표시하지 않으며, 게시 후 공개 주소에서 다시 확인한다.
- CPU 4배 감속 중 영어→일본어→한국어→영어 클릭 전달 86/230/5/4ms. 마지막 선택 언어로 정상 입장하고 장면·시작 중복이 없음을 확인했다.
- 준비 안내 표시, 중복 클릭 방지, 초기 모듈 강제 실패, 언어 버튼 복구, 일본어 선택 후 새로고침·재입장을 통과했다.
- 세 터치 화면의 본문 16px 이상·주요 버튼/접속 상태 14px 이상, 줄바꿈과 가로 넘침 없음, 두 입장 안내 행동의 접근 가능성을 확인했다.
- 기존 14개 언어의 320×740 세로·740×320 가로에서 NPC 대화, 개인 공간의 시점·풍경·수행·귀환 버튼이 가려지지 않고 언어가 유지됨을 통과했다.
- 건축·산책길의 정점·법선·인덱스 및 최종 재질 색상·표면 픽셀·텍스처 해상도가 공개 v51과 정확히 같다. 가상 방문객 용량 20 유지.
- 원본 120개·체험판 59개 단위 검사 및 양쪽 타입/빌드 통과.
- PC 1440×900·터치 390×844에서 바닥 탭 이동, 다섯 아이템 자리 조회, 종·차/커피·기립·동전, 스님 인사, 자동 108배 시작/중단, 개인 공간 전시 저장·참배·명상·귀환/재입장 유지, 일정·야간을 통과했다. 실제 예약·결제 쓰기는 발생시키지 않았다.

증빙은 evidence/entry-optimization의 before, local, interfaces, quality에 보존한다. PC/터치 통합 동선과 공개 게시 결과는 같은 폴더의 journeys, published, publication.json으로 구분한다. 로컬 결과를 공개 검수 결과로 대신 표시하지 않는다.


## 공개 v52 최종 확인

체험판 v52, 소스 ae13ac94bc89d117b293900124ffd43ef91cf603, 배포 성공. 기존 공개 범위를 유지했다.

20Mbps·80ms / Chrome / Mac의 공개 주소에서 첫 방문 6.580초·재방문 4.366초로 기존 기준을 통과했다. 같은 네트워크 모의의 기존 공개 v51 첫 방문 10.056초와 구분해 기록한다. 고품질을 낮추지 않았으며, 이 수치는 모든 PC에 대한 속도 보장이 아니다.

CPU 4배 감속 중 공개 언어 클릭 전달은 영어/일본어/한국어/영어 각각 136/88/213/4ms였다. 시작 버튼은 장면 준비 중 실제 포인터 입력으로 누르고 진행 상태 표시 및 정상 입장을 확인했다. 공개 주소의 세 모바일 화면에서도 16px 본문·14px 주요 조작, 안내 행동 접근을 통과했다. 초기 모듈 강제 실패 후 언어 변경·일본어 새로고침·정상 재입장도 통과했다.

게시 후 검수는 published/result.json, 게시 영수증은 publication.json에 보존한다. 실휴대폰·실제 저사양 PC·참가자 평가 결과는 아니며, 가격·결제 및 외부 서버 설정은 변경하지 않았다.
