# M1 검증 증거 — 2026-11-06

현재 장면: `m1-slice-002`. 정식 품질 합격이나 M1 완료를 의미하지 않는다.

## 현재 결과

- `desktop-dusk-1000.json`: 생산용 빌드를 localhost에서 실행. Apple M5 Pro / ANGLE Metal, 렌더 크기 593×903, 해질녘·고품질·연등 1,000개·고정 시점. 약 69.76초 중 2초 워밍업 제외, 8,131프레임. 평균 120.00 FPS, 1% low 105.93 FPS. 실제 모바일이 아니며 필수 5분 동선/20분 발열 시험을 대체하지 않는다.
- 첫 준비 프레임 205.3ms는 캐시·네트워크 통제가 없는 localhost 참고치다. 운영 로딩 합격 근거가 아니다. JS heap은 GPU/전체 메모리가 아니다.
- `m1-slice-002-wide.png`: 색상 수정 후 전체 장면.
- `m1-day-detail.png`: 낮, 대웅전 단청 근접 보기.
- `m1-night-owned.png`: 밤, 경량 품질, 반짝임 완화, 내 연등 보기. 기본 100개 샘플에서 소유 연등의 발광·표식 확인. 실제 구매/서버 소유권은 미구현.
- 측정 후 진단창에서 소유 연등을 선택할 때 소개 패널과 선택 메뉴를 동기화하는 UI 수정만 추가했다. 렌더링·측정 코드는 그대로다.

## 이력과 검증 범위

`pre-color-fix-*`는 발광 텍스처 수정 전 이력으로 최종 결과에서 제외한다.

자동 검증: 슬롯 ID/좌표의 밀도 변경 안정성, 잘못된 밀도 거부, 12공간 정의, FPS 계산, 측정 무효화, 종료 시각 고정에 대한 6개 테스트와 TypeScript/생산용 빌드 통과. 번들 크기 경고는 남아 있으며 추가 최적화 판단이 필요하다.

UI에서 시점 전환, 낮/해질녘/밤, 품질 선택, 반짝임 완화, 샘플 밀도, 측정 시작/종료·기록 확인을 수행했다. 저사양 실기기 모델은 사용자 답변 ‘미정’. 모바일 FPS·발열·앱 성능·종교/건축 감수·시각 승인은 미검증이다.
