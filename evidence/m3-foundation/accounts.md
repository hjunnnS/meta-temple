# M3 로컬 계정·데이터 검수

사용자가 승인한 독립 PostgreSQL 17과 시험 주소를 사용했다. 브라우저에서 받은 링크로 로그인하고 같은 링크의 두 번째 사용이 거절되는지 확인했다. 두 번째 독립 브라우저에서 같은 시험 계정으로 로그인하면 같은 주문·설치 ID가 조회됐고, 다른 시험 계정은 빈 목록을 받았다. 로그아웃한 브라우저의 전용 조회는 401을 반환했다. 표본 주문은 DB 검수용으로 생성한 이력이다.

공개 구역 API의 다섯 종류 531자리와 M2 좌표가 일치했다. M2 미리보기에서 찾기 메뉴·이동 취소·내 연등 카메라 바로가기가 사라졌고, 직접 입장해 걷기 조작이 가능했다. DB 제약 검수는 저장소 루트에서 `node server/service/check-db.mjs`로 재실행할 수 있다.
