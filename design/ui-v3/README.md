# UI/UX 개선 시안 03

실제 서비스와 분리된 로컬 시안. design/ui-v2의 실제 사찰 화면을 배경으로 재사용하며 src·server·판매 정책·구매 데이터는 변경하지 않는다. index.html은 비교용 뷰어, app.html은 조작 가능한 시안이다. 로그인과 결제는 시안 내부 상태 전환이며 외부 인증·주문 API를 호출하지 않는다.

- M2 / Epic E01 #1 / Implementation #27 후속: 고정 최소 글자 크기, 44px 조작 영역, 모바일 단계별 창 높이, 기본 dialog 초점·Esc·복귀, 지도와 현장 동작 구분.
- M3 / Epic E01 #1 / Implementation #35 후속: 다섯 상품 선택, 줄→자리 확대, 신청 문구·기간·금액·확인·예약. 게스트 참배·명상과 회원 108배의 진입 분리. 닫기·취소 시 같은 위치와 초안 유지.
- M4 / Epic E01 #1·E04 #4 / Implementation #64 후속: 만석·선택 충돌·로그인 취소·예약 만료·결제 확인 중·설치 복구·연결 끊김 시안과 핵심 동선 검증.
- M4 / Epic E05 #74 / #76·#77: 다국어 실제 화면 적용은 후속. 이번은 한국어 시안이며 외국어 화면까지 검수했다고 간주하지 않는다.

완료 조건: 웹·320/390px에서 읽을 수 있는 조작 화면, 로그인은 예약·108배 시작 시점에 요청, 중단 후 동일 장소, 기간·금액의 확인 영역, 실패 시 초안 및 같은 주문 유지. 기존 승인 상태와 이슈 번호를 보존하고 새로운 이슈는 만들지 않는다. 이번 시안 작업량 S, 실제 서비스 구현 추정에는 합산하지 않음. 별도 목표 날짜 미설정.

7·30일은 시안 표시, 가격 미정. 자리 수·공간 좌표·문구 제한은 시연이며 최종 판매 정책이 아니다. 실제 인증·결제·3D 캐릭터/배치 변경은 시안 범위에 포함하지 않는다. 이동 화면은 준비된 배경을 바꾸는 방식이며 실제 보행이 아니다. 지도는 현 배치를 단순화한 안내도다. 개인 공간 전시 항목은 시안 데이터다.
