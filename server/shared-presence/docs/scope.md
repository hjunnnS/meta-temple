# 공동 방문 테스트 서버

M3 / Epic #3 / Implementation #53·#54 후속 및 M4 #68 검수. 프런트엔드는 기존 사사 체험판이다. 새 Issue나 Milestone은 만들지 않는다. 선행은 Mac 없이 3명이 공동 방문하는 사용자 승인이다. 예상 구현 M, 검수 S, 배포 대기는 별도다.

완료 조건: 독립 브라우저 3명의 상호 입장·이동·참배·법복·얼굴, 퇴장·재접속, 개인 공간 격리 및 AI 방문객 수 조절. 클라이언트/서버 좌표·레이아웃 버전 일치. 만료·위조된 키로 다른 세션을 조작할 수 없고 역순 메시지는 최신 자세를 덮어쓰지 않아야 한다.

익명 세션 키는 브라우저 메모리에만 두고 서버에는 해시를 보관한다. 위치와 동작은 현재 값만 덮어쓰고 30초 이상 비활성 세션은 표시에서 제외한다. 만료 행은 다음 입장 때 삭제한다. 계정·이메일·주문·가격·결제·개인 방 내용은 이 서버에 저장하지 않는다. 기존 시험 채널 정원 20명을 유지하며 이번 검수 인원은 3명이다. 정식 운영/50명 부하 합격을 뜻하지 않는다.

구현: Cloudflare Worker와 Sites가 연결하는 D1 바인딩. 배포 시 스키마 전용 마이그레이션을 적용한다. 현재 위치·동작 서버만 분리하여 기존 정적 사찰과 아이템 시험 기능은 유지한다. 호출 출처는 기존 체험판 및 로컬 검수 주소로 제한하고 교차 출처 응답은 이 주소에만 허용한다. CORS 자체를 사용자 인증으로 취급하지 않으며 쓰기 권한은 개별 세션 키로 확인한다.
