# M3 로컬 시험 서비스

Node 24와 PostgreSQL 17의 initdb, pg_ctl, psql, createdb가 PATH에 있는 Mac에서 저장소 루트의 `npm run service`로 시작한다. 브라우저 주소는 http://127.0.0.1:4330 이다. M2 미리보기는 4320을 사용한다.

데이터베이스는 .m3-local/db에 저장하고 이 프로젝트 전용 Unix 소켓으로 연결한다. 서비스의 첫 실행에서 버전이 붙은 마이그레이션을 트랜잭션으로 적용한다. 531자리의 위치와 기존 식별자는 M2와 공유한다. 설치 이력은 주문과 계정이 일치해야 생성할 수 있다. M2 샘플 설치를 서비스의 구매 기록으로 복사하지 않는다.

계정 메뉴에서 visitor@example.test처럼 시험 주소를 입력한다. 이 Mac의 .m3-local/mail에 생성된 가장 최근의 해당 수신자 메시지에서 링크를 열고 ‘로그인 완료’를 누른다. 외부 메일 발송은 실제 발송 환경 승인 후 연결한다. 링크는 10분 내 한 번만 사용할 수 있고 새 링크 요청 시 이전 링크는 폐기된다. 이 로컬 검수용 세션은 24시간 동안 유효하며 다른 브라우저에서 별도 링크로 같은 계정의 이력을 확인할 수 있다. 기본 탐방은 로그인 없이 이용한다.

종료 시 Vite를 종료하고 `pg_ctl -D .m3-local/db -m fast stop`으로 이 프로젝트의 DB를 정지할 수 있다. 데이터와 시험 우편함은 Git에 포함되지 않는다.

시험 운영 화면은 로그인 후 `/staff.html`에서 연다. 이 Mac의 데이터베이스 관리자가 기존 시험 계정에만 역할을 지정한다. 예를 들어 아래 SQL의 주소를 해당 시험 계정으로 바꾼다. 역할 값은 접수·환불 `desk`, 상품 운영 `catalog`, 공개 문구 감수 `moderation`이다.

```sql
INSERT INTO staff_roles(account_id,role)
SELECT id,'catalog' FROM accounts WHERE email='operator@example.test'
ON CONFLICT DO NOTHING;
```

## 시험 운영·복원

서비스가 켜져 있는 동안 서울 날짜 기준 하루 한 번 백업한다. Mac이나 서비스가 꺼져 있으면 다음 기동 시 그날 백업을 만든다. 최근 7일의 보관 위치는 `.m3-local/backups`이다. 로그인 링크와 세션은 백업에서 제외한다. 복원 검수 명령은 `node --experimental-strip-types server/service/backup.mjs verify`다. 새 검수 DB에 복원하고 같은 스냅숏의 테이블별 수량·내용 지문을 대조한 후 검수 DB를 정리한다. 삭제 전의 봉헌 문구가 남을 수 있는 과거 백업은 격리 검수용으로만 연다.

설치·환불 실패는 장애 알림에 기록된다. 결제 대기 10분과 예약 생성 후 약 10분의 정체도 표시한다. 접수 담당자는 운영 화면에서 주문을 조회하고 사유를 남겨 알림을 확인한다. 설치 재시도와 환불은 기존 워커가 같은 주문과 영수증을 사용한다. 결제 결과를 모르면 주문 재조회로 확인한다.

웹 버전을 되돌릴 때는 `sh scripts/m3-rollback-web.sh 26f8b36`으로 검증한 웹 파일을 별도 디렉터리에 준비한다. 해당 디렉터리의 정적 파일을 기존 웹 주소에 제공하고 `/api/service`는 현재 서비스로 연결한다. 호환 범위는 아래 증거에서 검수한 버전이다. 동일 데이터베이스와 현재의 거래·삭제 워커를 유지한다. 로컬 미리보기는 기본적으로 현재 소스를 제공한다. 실제 호스팅 배포는 별도 단계다.

로컬 롤백을 실행하려면 미리보기 서버를 종료한 후 위 명령이 출력한 디렉터리의 이름을 지정해 `M3_WEB_RELEASE=web-release-XXXXXX npm run service`를 실행한다. 4330에서 이전 웹 화면과 현재 API·워커를 함께 제공한다. 최신 화면으로 복귀할 때는 해당 변수 없이 실행한다.
